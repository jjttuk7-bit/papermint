# 2026-08-02 논문 요약
### - GQA: 다중 헤드 체크포인트에서 일반화된 다중 쿼리 Transformer 모델 훈련

**카테고리**: NLP, Efficiency | **upvotes**: 6 | [arXiv](https://arxiv.org/abs/2305.13245)

> 기존 다중 헤드 언어 모델을 소량의 계산 비용으로 다중 쿼리 어텐션을 사용하도록 업트레이닝하는 방법을 제안합니다.

**핵심 기여**:
- 기존 다중 헤드 모델을 5%의 원래 사전 훈련 계산 비용으로 다중 쿼리 어텐션을 사용하도록 업트레이닝하는 방법을 제안했습니다.
- 중간 수의 키-값 헤드를 사용하는 다중 쿼리 어텐션의 일반화된 형태인 그룹 쿼리 어텐션을 도입했습니다.
- 업트레이닝된 그룹 쿼리 어텐션이 다중 헤드 어텐션에 가까운 품질을 다중 쿼리 어텐션과 유사한 속도로 달성함을 입증했습니다.

**초록**:

단일 키-값 헤드만 사용하는 다중 쿼리 어텐션 (MQA)은 디코더 추론 속도를 크게 향상시킵니다. 그러나 MQA는 품질 저하를 초래할 수 있으며, 단지 더 빠른 추론을 위해 별도의 모델을 훈련하는 것이 바람직하지 않을 수 있습니다. 우리는 (1) 기존 다중 헤드 언어 모델 체크포인트를 5%의 원래 사전 훈련 계산 비용으로 MQA를 사용하는 모델로 업트레이닝하는 방법을 제안하며, (2) 중간 수의 키-값 헤드를 사용하는 다중 쿼리 어텐션의 일반화된 형태인 그룹 쿼리 어텐션 (GQA)을 도입합니다. 업트레이닝된 GQA가 다중 헤드 어텐션에 가까운 품질을 MQA와 유사한 속도로 달성함을 보여줍니다.

### - Faster R-CNN: 영역 제안 네트워크를 통한 실시간 객체 탐지

**카테고리**: CV, Efficiency | **upvotes**: 2 | [arXiv](https://arxiv.org/abs/1506.01497)

> Faster R-CNN은 실시간 객체 탐지 효율성을 높이기 위해 영역 제안 네트워크를 제안합니다.

**핵심 기여**:
- 탐지 네트워크와 합성곱 특징을 공유하는 영역 제안 네트워크(RPN)를 도입했습니다.
- RPN과 Fast R-CNN을 하나의 네트워크로 통합하여 효율적인 객체 탐지를 구현했습니다.
- 이미지당 300개의 제안만으로 VGG-16 모델에서 5fps의 성능으로 최고 수준의 탐지 정확도를 달성했습니다.

**초록**:

최신 객체 탐지 네트워크는 객체 위치를 가정하기 위해 영역 제안 알고리즘에 의존합니다. SPPnet과 Fast R-CNN과 같은 발전은 이러한 탐지 네트워크의 실행 시간을 줄였으나, 영역 제안 계산이 병목현상이 되고 있습니다. 이 연구에서는 탐지 네트워크와 전체 이미지 합성곱 특징을 공유하는 영역 제안 네트워크(RPN)를 소개하여 거의 비용이 들지 않는 영역 제안을 가능하게 했습니다. RPN은 각 위치에서 객체 경계와 객체성 점수를 동시에 예측하는 완전 합성곱 네트워크입니다. RPN은 고품질의 영역 제안을 생성하도록 종단간 학습되며, 이는 Fast R-CNN에 의해 탐지에 사용됩니다. 우리는 또한 RPN과 Fast R-CNN을 합성곱 특징을 공유하여 하나의 네트워크로 통합했습니다. '어텐션 메커니즘 (Attention Mechanism)'이라는 최근 유행하는 용어를 사용하여, RPN 구성 요소는 통합 네트워크가 어디를 볼지 알려줍니다. 매우 깊은 VGG-16 모델의 경우, 우리의 탐지 시스템은 GPU에서 모든 단계를 포함하여 5fps의 프레임 속도를 가지며, PASCAL VOC 2007, 2012, MS COCO 데이터셋에서 이미지당 300개의 제안만으로 최고 수준의 객체 탐지 정확도를 달성했습니다. ILSVRC 및 COCO 2015 대회에서 Faster R-CNN과 RPN은 여러 트랙에서 1위 수상작의 기초가 되었습니다. 코드는 공개되어 있습니다.

### - 통합 텍스트-텍스트 변환기를 통한 전이 학습의 한계 탐색

**카테고리**: NLP | **upvotes**: 19 | [arXiv](https://arxiv.org/abs/1910.10683)

> NLP 전이 학습을 위한 통합 텍스트-텍스트 프레임워크를 제안하여 다양한 작업에서 최고 성능을 달성합니다.

**핵심 기여**:
- 모든 언어 문제를 위한 통합 텍스트-텍스트 프레임워크를 제안합니다.
- 다양한 사전 학습 목표와 아키텍처를 비교하는 체계적인 연구를 수행합니다.
- 여러 언어 이해 벤치마크에서 최고 성능을 달성합니다.

**초록**:

전이 학습은 데이터가 풍부한 작업에서 모델을 사전 학습한 후 다운스트림 작업에 미세 조정하는 강력한 기법으로 부상했습니다. 전이 학습의 효과는 다양한 접근 방식, 방법론 및 실천을 낳았습니다. 본 논문에서는 모든 텍스트 기반 언어 문제를 텍스트-텍스트 형식으로 변환하는 통합 프레임워크를 소개하여 NLP 전이 학습 기술의 전반적인 모습을 탐구합니다. 우리의 체계적인 연구는 수십 개의 언어 이해 작업에서 사전 학습 목표, 아키텍처, 비지도 데이터 세트, 전이 접근 방식을 비교합니다. 탐구에서 얻은 통찰력과 규모, 새로운 'Colossal Clean Crawled Corpus'를 결합하여 요약, 질문 응답, 텍스트 분류 등 많은 벤치마크에서 최고 성능을 달성합니다. NLP 전이 학습에 대한 향후 연구를 촉진하기 위해 데이터 세트, 사전 학습된 모델 및 코드를 공개합니다.
