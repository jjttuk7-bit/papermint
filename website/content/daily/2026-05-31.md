# 2026-05-31 논문 요약
### - GQA: 멀티 헤드 체크포인트에서 일반화된 멀티 쿼리 트랜스포머 모델 훈련

**카테고리**: NLP, Efficiency | **upvotes**: 6 | [arXiv](https://arxiv.org/abs/2305.13245)

> 멀티 헤드 트랜스포머 모델을 멀티 쿼리 및 그룹 쿼리 어텐션으로 변환하여 품질 손실 없이 추론 속도를 높이는 방법을 제안합니다.

**핵심 기여**:
- 기존 멀티 헤드 트랜스포머 모델을 멀티 쿼리 어텐션으로 업트레인하는 방법을 제안하며, 원래 사전 학습 계산의 5%만 사용합니다.
- 중간 수의 키-값 헤드를 사용하는 멀티 쿼리 어텐션의 일반화로서 그룹 쿼리 어텐션을 소개합니다.
- 업트레인된 그룹 쿼리 어텐션 모델이 멀티 헤드 어텐션과 유사한 품질을 유지하며 멀티 쿼리 어텐션과 유사한 추론 속도를 달성할 수 있음을 보여줍니다.

**초록**:

단일 키-값 헤드만 사용하는 멀티 쿼리 어텐션 (MQA)은 디코더 추론 속도를 획기적으로 높입니다. 그러나 MQA는 품질 저하를 초래할 수 있으며, 단순히 빠른 추론을 위해 별도의 모델을 훈련하는 것은 바람직하지 않을 수 있습니다. 우리는 (1) 기존 멀티 헤드 언어 모델 체크포인트를 MQA를 사용하는 모델로 업트레인하기 위한 레시피를 제안하며, 이는 원래 사전 학습 계산의 5%만 사용합니다. 또한 (2) 중간 수의 키-값 헤드를 사용하는 멀티 쿼리 어텐션의 일반화로서 그룹 쿼리 어텐션 (GQA)을 소개합니다. 업트레인된 GQA가 MQA와 유사한 속도로 멀티 헤드 어텐션과 유사한 품질을 달성할 수 있음을 보여줍니다.

### - Faster R-CNN: 영역 제안 네트워크를 통한 실시간 객체 탐지

**카테고리**: CV, Efficiency | **upvotes**: 2 | [arXiv](https://arxiv.org/abs/1506.01497)

> 실시간 객체 탐지를 개선하기 위해 검출 네트워크와 컨볼루션 특징을 공유하는 영역 제안 네트워크 (RPN)를 제안합니다.

**핵심 기여**:
- 검출 네트워크와 컨볼루션 특징을 공유하는 영역 제안 네트워크 (RPN)를 소개합니다.
- RPN은 각 위치에서 객체 경계와 객체성 점수를 동시에 예측합니다.
- RPN과 Fast R-CNN을 하나의 네트워크로 통합하여 효율적인 객체 탐지를 구현합니다.

**초록**:

최신 객체 탐지 네트워크는 객체 위치를 추정하기 위해 영역 제안 알고리즘에 의존합니다. SPPnet과 Fast R-CNN과 같은 발전은 이러한 탐지 네트워크의 실행 시간을 줄였지만, 영역 제안 계산이 병목 현상으로 드러났습니다. 본 연구에서는 검출 네트워크와 전체 이미지 컨볼루션 특징을 공유하여 거의 비용이 들지 않는 영역 제안을 가능하게 하는 영역 제안 네트워크 (RPN)를 소개합니다. RPN은 완전한 컨볼루션 네트워크로, 각 위치에서 객체 경계와 객체성 점수를 동시에 예측합니다. RPN은 고품질의 영역 제안을 생성하도록 종단 간 학습되며, 이는 Fast R-CNN에 의해 탐지에 사용됩니다. 우리는 RPN과 Fast R-CNN을 컨볼루션 특징을 공유하여 하나의 네트워크로 통합합니다. 최근 인기를 끌고 있는 신경망의 '어텐션' 메커니즘 용어를 사용하여, RPN 구성 요소는 통합 네트워크에 어디를 볼지 알려줍니다. 매우 깊은 VGG-16 모델에서, 우리의 탐지 시스템은 GPU에서 5fps의 프레임 속도를 가지며, PASCAL VOC 2007, 2012, MS COCO 데이터셋에서 이미지 당 300개의 제안만으로 최신 객체 탐지 정확도를 달성합니다. ILSVRC와 COCO 2015 대회에서, Faster R-CNN과 RPN은 여러 트랙에서 1위 입상에 기여한 기반이 되었습니다. 코드는 공개되어 있습니다.

### - 통합 텍스트-텍스트 트랜스포머를 통한 전이 학습의 한계 탐색

**카테고리**: NLP | **upvotes**: 19 | [arXiv](https://arxiv.org/abs/1910.10683)

> NLP에서 전이 학습을 위한 통합 텍스트-텍스트 프레임워크를 제안하여 다양한 작업에서 최고 성능을 달성합니다.

**핵심 기여**:
- 모든 텍스트 기반 언어 문제를 처리하기 위한 통합 텍스트-텍스트 프레임워크를 도입했습니다.
- 다양한 사전 학습 목표와 아키텍처를 여러 언어 작업에서 비교하는 체계적인 연구를 수행했습니다.
- 요약, 질문 응답, 텍스트 분류를 위한 벤치마크에서 최고 성능을 달성했습니다.

**초록**:

전이 학습은 데이터가 풍부한 작업에서 모델을 먼저 사전 학습한 후 다운스트림 작업에 미세 조정하는 기법으로, 자연어 처리에서 강력한 기법으로 부상했습니다. 전이 학습의 효과는 다양한 접근법, 방법론, 실천을 탄생시켰습니다. 본 논문에서는 모든 텍스트 기반 언어 문제를 텍스트-텍스트 형식으로 변환하는 통합 프레임워크를 도입하여 NLP 전이 학습 기법의 전반적인 모습을 탐색합니다. 체계적인 연구를 통해 사전 학습 목표, 아키텍처, 비지도 데이터 세트, 전이 접근법 및 기타 요소를 수십 개의 언어 이해 작업에서 비교합니다. 우리의 탐색에서 얻은 통찰력과 새로운 'Colossal Clean Crawled Corpus'를 결합하여 요약, 질문 응답, 텍스트 분류 등 여러 벤치마크에서 최고 성능을 달성합니다. NLP를 위한 전이 학습의 미래 연구를 촉진하기 위해 데이터 세트, 사전 학습된 모델 및 코드를 공개합니다.
