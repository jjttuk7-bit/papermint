### - EnvHarness: 에이전트 학습을 위한 정적 세계의 각성

**카테고리**: RL, Agent | **upvotes**: 235 | [arXiv](https://arxiv.org/abs/2608.19880) | [Project](https://envharness.com/)

> EnvHarness는 에이전트 학습을 위해 정적 환경을 동적으로 재구성하는 방법을 제안합니다.

**핵심 기여**:
- EnvHarness라는 프로그래머블 레이어를 도입하여 정적 환경의 핵심 로직을 수정하지 않고 재구성합니다.
- 에이전트 실행 경로를 분석하여 EnvHarness 구성 요소를 자동 생성하는 EnvRigger 시스템을 제안합니다.
- EnvHarness를 적용하여 여러 벤치마크에서 성능을 크게 향상시켰습니다.

**초록**:

LLM 에이전트는 환경과의 상호작용을 통해 학습하지만, 이러한 환경은 수작업으로 구축되어 정적입니다. 에이전트의 약점을 인식하지 못하고 개선되면서 곧 뒤처지게 됩니다. 최근 환경 생성 방법은 이를 해결하려 하지만, 도메인별 파이프라인이 필요하고 비용이 많이 들거나 신뢰할 수 없는 검증자에 의존하며 여전히 정적 환경을 생성합니다. 환경을 처음부터 다시 구축하는 엔지니어링 부담을 줄이기 위해, 우리는 EnvHarness를 제안합니다. 이는 정적 환경을 감싸는 플러그인 구성 요소의 프로그래머블 레이어로, 기본 로직을 수정하지 않고 환경의 동작을 재구성합니다. 표준 인터페이스를 통해 작동하여 다양한 도메인에 적용되며, 재구성된 환경이 원래의 검증자를 유지하도록 보장합니다. 이 프로세스를 자동화하기 위해, 우리는 EnvRigger를 도입하여 목표 정책을 블랙박스로 취급하고 실행 경로를 관찰하여 진단된 결함을 목표로 EnvHarness 구성 요소를 합성하고, 새로운 롤아웃을 통해 이를 검증합니다. 네 가지 도메인에서 다섯 가지 벤치마크에 걸쳐 EnvHarness는 원래 환경과 도메인별 환경 생성 파이프라인보다 우수한 성능을 보이며, 보유된 인스턴스에서 최대 9.0점 향상과 9.8% 적은 실행 단계를 달성했습니다. 또한, EnvHarness는 강화 학습을 위한 우수한 최적화 신호를 제공하여 정책과 환경의 지속적이고 목표 지향적인 공동 진화를 가능하게 합니다.

### - FACET: 터미널 작업 생성에서 원본 의도와 실행 가능한 상태 보존

**카테고리**: RL, Agent, Efficiency | **upvotes**: 107 | [arXiv](https://arxiv.org/abs/2608.18580) | [Project](https://stokou.github.io/FACET-Terminal/)

> FACET는 터미널 작업 생성에서 원본 의도와 실행 가능한 상태를 보존하는 프레임워크를 제안합니다.

**핵심 기여**:
- 일관성 있고 정보가 풍부한 터미널 작업 생성을 위한 FACET 프레임워크를 소개합니다.
- 에이전트 기술을 일관된 시나리오로 재구성하여 아티팩트 간의 일관성을 보장합니다.
- 실행 기반 검증과 목표 지향적 수정을 통해 아티팩트별 오류를 수정합니다.

**초록**:

터미널 에이전트를 훈련하려면 확장 가능한 실행 감독이 필요하지만, 고품질 터미널 작업을 합성하는 것은 여전히 어렵습니다. 각 작업은 지시문, 초기화된 환경, 참조 솔루션 및 실행 가능한 검증기를 결합합니다. 이 아티팩트들이 일관되지 않은 가정에서 생성되면, 결과 작업은 해결 불가능하거나 잘못 평가될 수 있습니다. 한편, 다단계 합성은 원본 소스에 코딩된 목표, 의존성, 상태 전환 및 절차적 제약을 버릴 수 있습니다. FACET (Fine-grained Agentic Construction of Executable Tasks)을 소개합니다. 이 프레임워크는 정보 보존과 아티팩트 간 일관성을 모두 해결합니다. FACET는 관련 에이전트 기술을 일관되고 정보가 풍부한 시나리오로 재구성한 후, 실행 환경을 실현하고 수리한 다음 최종 작업 아티팩트를 생성합니다. 결과 컨테이너 상태는 지시문, 솔루션 및 검증기에 대한 공유 기반 역할을 하며, 실행 기반 검증과 목표 지향적 수정을 통해 불필요하게 유효한 구성 요소를 재생성하지 않고 아티팩트별 오류를 수정합니다. FACET는 밀집된 실행 가능한 검사를 가진 복잡한 터미널 작업을 생성하며, 이러한 작업에서 수집된 성공적인 경로는 효과적이고 데이터 효율적인 감독을 제공합니다. 여러 스케일에 걸친 모델의 미세 조정은 Terminal-Bench 2.1에서의 성능을 지속적으로 향상시키며, 대안 생성 방식에 대한 분석은 작업 유효성과 솔루션-검증기 정렬을 위한 환경 기반 구축의 중요성을 뒷받침합니다. 이러한 결과는 확장 가능한 터미널 작업 생성을 위한 핵심 원칙으로 원본 의도 보존과 공유 실행 상태 기반을 확립합니다.

### - 4DAnyone: 단안 비디오로 누구나 4D로 만들기

**카테고리**: Video, CV | **upvotes**: 58 | [arXiv](https://arxiv.org/abs/2608.20335) | [Project](https://4danyone.github.io/)

> 4DAnyone은 단안 비디오로부터 4D 인간을 재구성하며, 다중 뷰 일관성 문제를 해결합니다.

**핵심 기여**:
- 비교되지 않은 단안 비디오로부터 4D 인간을 재구성하는 4DAnyone 프레임워크를 소개합니다.
- Reference Context Packing과 Target Context Routing으로 제한된 어텐션 컨텍스트 문제를 해결합니다.
- 새로운 뷰 비디오 품질과 4DGS 재구성에서 우수한 성능을 입증합니다.

**초록**:

4DAnyone을 소개합니다. 이는 보정되지 않은 단안 비디오로부터 4D 인간을 재구성하는 프레임워크입니다. 재구성 등급의 다중 뷰 일관성 비디오를 생성하고 이를 4D Gaussian Splatting (4DGS)로 승화합니다. 기존의 카메라 제어 비디오 확산 모델은 그럴듯한 새로운 뷰 비디오를 합성하지만, 4DGS 재구성에 필요한 수십 개의 목표 뷰로 확장될 때 일관성을 유지하지 못합니다. 우리는 이 실패를 제한된 어텐션 컨텍스트 문제로 식별합니다. 목표 뷰가 단일 DiT 전진 패스의 용량을 초과할 때 그룹으로 나누어야 하며, 두 개의 결합된 병목 현상이 발생합니다. 참조 컨텍스트 측면에서는, 모든 이전에 생성된 뷰를 조건으로 하는 것이 O(N)으로 증가하여 뷰 간 외관 지침이 약해집니다. 목표 컨텍스트 측면에서는, 분리된 그룹이 직접 정보를 교환할 수 없어 전역 구조 드리프트가 발생합니다. 4DAnyone은 두 가지 보완적인 설계로 두 병목 현상을 해결합니다. Reference Context Packing (RCP)은 O(1) 참조 컨텍스트 복잡성으로 증가하는 참조 뷰를 고정 길이의 혼합 해상도 컨텍스트로 압축합니다. Target Context Routing (TCR)은 노이즈가 높은 단계에서 그룹 간 컨텍스트를 공유하고 노이즈가 낮은 단계에서 세부 사항을 안정화하기 위해 디노이징 중 목표 뷰 그룹을 회전시킵니다. 우리는 또한 자체 게임 엔진을 사용하여 MVGameHuman 데이터셋을 구축하고, 라이트 스테이지 및 자연 비디오 데이터셋과 결합하여 훈련에 사용합니다. DNA-Rendering과 DyMVHumans에 대한 실험에서 4DAnyone은 새로운 뷰 비디오 품질과 다운스트림 4DGS 재구성에서 이전 방법보다 우수한 성능을 보여주며, 자연 상태에서의 강력한 일반화를 제공합니다. 비디오 결과와 소스 코드는 프로젝트 페이지에서 확인할 수 있습니다: https://4danyone.github.io.

### - SWE-bench Science: 코딩 에이전트가 과학의 엔지니어링 작업을 해결할 수 있는가?

**카테고리**: Agent, Alignment | **upvotes**: 56 | [arXiv](https://arxiv.org/abs/2608.19799) | [Project](https://swescience.github.io)

> 과학 소프트웨어 엔지니어링 작업에서 코딩 에이전트를 평가하는 벤치마크인 SWE-bench Science를 소개합니다.

**핵심 기여**:
- 20개 과학 분야의 98개 GitHub 저장소에서 119개 작업을 포함한 SWE-bench Science 벤치마크를 소개합니다.
- 작업을 이슈 중심, 전문가 탐색, 엔지니어링 통합의 세 가지 패러다임으로 분류합니다.
- 과학 소프트웨어 수리 시 코딩 에이전트의 네 가지 반복적인 실패 메커니즘을 식별합니다.

**초록**:

소프트웨어는 점점 더 과학 장비의 일부로 기능하며, 과학 코드의 실패는 프로그램 동작뿐 아니라 과학적 결론의 근거까지 위협할 수 있습니다. 그러나 기존의 코딩 에이전트 평가에서는 주로 총체적인 작업 성공에 중점을 두어, 과학 소프트웨어 수리 시 에이전트가 실패하는 이유에 대한 통찰을 제공하지 못합니다. 우리는 SWE-bench Science를 소개합니다. 이는 20개 과학 분야에 걸친 98개 GitHub 저장소에서 119개의 작업으로 구성된 과학 소프트웨어 엔지니어링을 위한 저장소 수준의 벤치마크입니다. 각 작업은 이슈 중심, 전문가 탐색, 엔지니어링 통합의 세 가지 패러다임 중 하나로 분류됩니다. 가장 성능이 좋은 에이전트인 Claude Code with Opus-5 (max)조차도 pass@1에서 50% 미만의 성과를 보여, 과학 소프트웨어 엔지니어링이 제기하는 상당한 도전 과제를 강조합니다. 우리는 과학 지식이나 추상화의 부족, 잘못된 탐색이나 표면적 수리, 불완전한 수리 범위나 시스템 통합, 관찰된 사례를 넘어 과학 지식을 일반화하는 데 실패하는 등 네 가지 반복적인 실패 메커니즘을 식별합니다. 우리는 저장소와 실행 가능한 엔지니어링 컨텍스트를 유지하면서 명시적인 과학 지침을 제거하는 페어드 절제를 추가로 수행합니다. 결과는 과학 지식이 일관되게 유익하지 않다는 것을 보여줍니다. 잘 정립된 정보는 수리를 제한하고 평균 성능과 토큰 효율성을 개선할 수 있지만, 잘 맞지 않는 지침은 고착을 유발하고 정확한 수리 성공을 반드시 개선하지는 않습니다. SWE-bench Science는 과학 소프트웨어 엔지니어링에서 코딩 에이전트의 역량과 실패 메커니즘을 연구하기 위한 광범위한 테스트베드를 제공합니다.

### - WithEveryone: 그룹 이미지 생성을 위한 통합 계획 및 정체성 기반

**카테고리**: CV, Multimodal | **upvotes**: 38 | [arXiv](https://arxiv.org/abs/2608.20336) | [Project](https://doby-xu.github.io/WithEveryone/)

> 정체성 유지를 위한 그룹 이미지 생성 프레임워크를 제안하여 유사성을 높이고 아티팩트를 줄입니다.

**핵심 기여**:
- 최대 10명의 정체성을 가진 그룹 이미지를 생성하는 WithEveryone 프레임워크를 소개합니다.
- 주석이 달린 얼굴 영역을 사용하여 의도된 정체성을 직접 감독하는 Layout-Grounded ID Loss를 제안합니다.
- 기존 모델 대비 목표-문맥 정체성 유사성을 높이고 복사-붙여넣기 아티팩트를 줄였습니다.

**초록**:

정체성을 유지하는 이미지 생성은 장면에 여러 지정된 인물이 포함되어야 할 때 점점 신뢰할 수 없게 됩니다. 각 정체성을 유지하는 것 외에도, 모델은 각 참조를 개별 인물과 위치에 연결해야 하며, 학습 시 정체성 손실은 여러 예측된 얼굴 간의 대응을 설정해야 합니다. 우리는 최대 10명의 참조 정체성에 대한 그룹 이미지를 생성하기 위한 통합 프레임워크인 WithEveryone을 소개합니다. WithEveryone은 각 선택된 정체성을 주소가 지정된 토큰으로 주입하고, 구조화된 정체성-레이아웃 계획을 예측하며, 이를 시각적 조건으로 렌더링합니다. 핵심 목표인 Layout-Grounded ID Loss는 주석이 달린 얼굴 영역을 사용하여 의도된 정체성을 직접 감독하여 불안정한 임베딩 기반 얼굴 매칭을 피합니다; ID Representation Forcing은 이미지 합성 전에 각 정체성에 대한 예측을 추가로 학습합니다. 정체성 불일치 벤치마크에서 WithEveryone은 목표-문맥 정체성 유사성에서 최고 성능을 달성하며, GPT-Image-2의 0.462에서 0.499로 얼굴 유사성을 개선하고, 복사-붙여넣기 아티팩트를 0.169에서 0.055로 줄였습니다. 또한 요청된 정체성의 97.3%를 커버하며 중복률은 2.8%에 불과합니다. 이러한 결과는 명시적 정체성-레이아웃 기반이 직접 참조 얼굴 복사에 의존하지 않고 더 큰 그룹으로 확장할 수 있는 정체성 유지 생성을 가능하게 한다는 것을 보여줍니다.

### - 노이즈 제거 확산 암묵적 모델

**카테고리**: CV, Efficiency | **upvotes**: 4 | [arXiv](https://arxiv.org/abs/2010.02502)

> 이미지 생성 샘플링을 가속화하기 위해 DDIMs를 제안합니다.

**핵심 기여**:
- 더 빠른 샘플링을 위한 DDIMs를 소개합니다.
- DDPMs와 동일한 훈련 절차를 유지하면서 비마르코프 확산 과정을 사용합니다.
- DDIMs가 DDPMs보다 훨씬 빠르게 고품질 샘플을 생성할 수 있음을 실험적으로 입증합니다.

**초록**:

노이즈 제거 확산 확률 모델(DDPMs)은 적대적 훈련 없이도 고품질 이미지 생성을 달성했지만, 샘플을 생성하기 위해 많은 단계의 마르코프 체인을 시뮬레이션해야 합니다. 샘플링을 가속화하기 위해, 우리는 DDPMs와 동일한 훈련 절차를 가진 더 효율적인 반복적 암묵적 확률 모델인 노이즈 제거 확산 암묵적 모델(DDIMs)을 제안합니다. DDPMs에서는 생성 과정이 마르코프 확산 과정의 역으로 정의됩니다. 우리는 동일한 훈련 목표를 달성하지만, 역 과정에서 샘플링이 훨씬 빠를 수 있는 비마르코프 확산 과정을 구성합니다. 실험적으로 DDIMs가 DDPMs에 비해 실제 시간 기준으로 10배에서 50배 빠르게 고품질 샘플을 생성할 수 있음을 보여주며, 계산과 샘플 품질 간의 균형을 조절할 수 있고, 잠재 공간에서 직접 의미 있는 이미지 보간을 수행할 수 있습니다.

프롬프트 가능한 시각적 세그먼트를 해결하기 위한 기초 모델인 SAM 2를 소개합니다. 사용자 상호작용을 통해 모델과 데이터를 개선하는 데이터 엔진을 구축하여 현재까지 가장 큰 비디오 세그먼트 데이터셋을 수집했습니다. 우리의 모델은 실시간 비디오 처리를 위한 스트리밍 메모리를 갖춘 간단한 트랜스포머 아키텍처입니다. 우리의 데이터로 학습된 SAM 2는 다양한 작업에서 강력한 성능을 제공합니다. 비디오 세그먼트에서는 이전 접근법보다 3배 적은 상호작용으로 더 나은 정확도를 보입니다. 이미지 세그먼트에서는 SAM보다 더 정확하고 6배 빠릅니다. 우리의 데이터, 모델, 통찰력이 비디오 세그먼트 및 관련 인식 작업에 중요한 이정표가 될 것이라 믿습니다. 우리의 모델 버전, 데이터셋 및 인터랙티브 데모를 공개합니다.

### - 인간 피드백으로 지시를 따르는 언어 모델 학습

**카테고리**: NLP, Alignment, RL | **upvotes**: 26 | [arXiv](https://arxiv.org/abs/2203.02155)

> 사용자 의도에 맞게 언어 모델을 인간 피드백으로 미세 조정하는 방법을 제안합니다.

**핵심 기여**:
- 인간 피드백을 사용하여 언어 모델을 사용자 의도에 맞추는 접근법을 제시했습니다.
- 사용자 선호도에서 더 큰 모델을 능가하는 InstructGPT를 소개했습니다.
- InstructGPT가 진실성을 개선하고 유해한 출력을 줄이며 성능 저하를 최소화함을 보였습니다.

**초록**:

언어 모델을 더 크게 만드는 것이 사용자 의도를 더 잘 따르게 만드는 것은 아닙니다. 예를 들어, 대형 언어 모델은 진실되지 않거나, 유해하거나, 사용자에게 도움이 되지 않는 출력을 생성할 수 있습니다. 즉, 이러한 모델은 사용자와 일치하지 않습니다. 본 논문에서는 인간 피드백을 통해 언어 모델을 다양한 작업에서 사용자 의도에 맞추는 방법을 제시합니다. 레이블러가 작성한 프롬프트와 OpenAI API를 통해 제출된 프롬프트를 시작으로, 원하는 모델 행동에 대한 레이블러 시연 데이터를 수집하여 이를 사용해 GPT-3를 지도 학습으로 미세 조정했습니다. 이후 모델 출력의 순위를 매긴 데이터를 수집하여 인간 피드백으로 강화 학습을 통해 이 지도 모델을 추가로 미세 조정했습니다. 결과 모델을 InstructGPT라고 부릅니다. 인간 평가에서, 1.3B 파라미터의 InstructGPT 모델은 175B GPT-3보다 선호되었으며, 파라미터 수는 100배 적습니다. 더욱이, InstructGPT 모델은 진실성에서 개선을 보였고 유해한 출력 생성이 감소했으며, 공개 NLP 데이터셋에서의 성능 저하는 최소화되었습니다. InstructGPT가 여전히 간단한 실수를 저지르긴 하지만, 인간 피드백으로 미세 조정하는 것이 언어 모델을 인간 의도에 맞추는 유망한 방향임을 보여줍니다.
