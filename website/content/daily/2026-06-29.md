# 2026-06-29 논문 요약
### - FlashAttention-2: 더 나은 병렬성과 작업 분할을 통한 빠른 어텐션

**카테고리**: Efficiency, NLP | **upvotes**: 9 | [arXiv](https://arxiv.org/abs/2307.08691)

> Transformer에서 더 빠른 어텐션을 위한 FlashAttention-2를 제안합니다.

**핵심 기여**:
- GPU 효율성을 개선하기 위해 작업 분할을 향상시킨 FlashAttention-2를 소개합니다.
- 스레드 블록과 워프 분배를 최적화하여 FlashAttention 대비 2배의 속도 향상을 달성합니다.
- A100 GPU에서 GPT 스타일 모델의 훈련 속도를 최대 225 TFLOPs/s까지 보여줍니다.

**초록**:

Transformer를 더 긴 시퀀스 길이로 확장하는 것은 최근 몇 년간 주요 문제였습니다. 이는 언어 모델링과 고해상도 이미지 이해의 성능을 개선하고 코드, 오디오, 비디오 생성의 새로운 응용을 가능하게 합니다. 어텐션 레이어는 시퀀스 길이에 따라 실행 시간과 메모리가 제곱적으로 증가하여 주요 병목 현상이 됩니다. FlashAttention은 비대칭 GPU 메모리 계층을 활용하여 메모리를 크게 절약하고(선형 대 제곱) 실행 시간을 가속화합니다(최적화된 기준 대비 2-4배). 그러나 FlashAttention은 여전히 최적화된 행렬 곱셈(GEMM) 연산만큼 빠르지 않아 이론적 최대 FLOPs/s의 25-40%에 불과합니다. 비효율성은 GPU의 서로 다른 스레드 블록과 워프 간의 비효율적인 작업 분할로 인한 것으로, 낮은 점유율이나 불필요한 공유 메모리 읽기/쓰기를 야기합니다. 우리는 이러한 문제를 해결하기 위해 FlashAttention-2를 제안합니다. 특히, 비-행렬 곱셈 FLOPs 수를 줄이기 위해 알고리즘을 조정하고, 단일 헤드에서도 어텐션 계산을 여러 스레드 블록에 병렬화하여 점유율을 높이며, 각 스레드 블록 내에서 워프 간의 작업을 분배하여 공유 메모리를 통한 통신을 줄입니다. 이를 통해 FlashAttention 대비 약 2배의 속도 향상을 이루며, A100에서 이론적 최대 FLOPs/s의 50-73%에 도달하여 GEMM 연산의 효율성에 근접합니다. 우리는 GPT 스타일 모델을 훈련할 때 FlashAttention-2가 A100 GPU당 최대 225 TFLOPs/s의 훈련 속도를 달성함을 실증적으로 검증합니다.

### - 깊은 언어 이해를 갖춘 사진 같은 텍스트-이미지 확산 모델

**카테고리**: NLP, CV, Multimodal | **upvotes**: 1 | [arXiv](https://arxiv.org/abs/2205.11487)

> 고화질 사진 같은 이미지를 생성하는 텍스트-이미지 변환 모델 Imagen을 제안합니다.

**핵심 기여**:
- 고화질 사진 같은 이미지를 생성하는 텍스트-이미지 변환 모델 Imagen을 제안합니다.
- 대형 Transformer 언어 모델이 이미지 합성을 위한 텍스트 인코딩에 효과적임을 보여줍니다.
- 텍스트-이미지 모델 평가를 위한 벤치마크 DrawBench를 소개합니다.

**초록**:

Imagen은 전례 없는 수준의 사진 같은 이미지를 생성하고 깊은 언어 이해를 갖춘 텍스트-이미지 확산 모델입니다. Imagen은 대형 Transformer 언어 모델의 텍스트 이해 능력과 고품질 이미지 생성에 강점을 가진 확산 모델을 기반으로 합니다. 우리의 주요 발견은 텍스트만으로 사전 학습된 대형 언어 모델(예: T5)이 이미지 합성을 위한 텍스트 인코딩에 놀랍도록 효과적이라는 점입니다. Imagen에서 언어 모델의 크기를 늘리면 이미지 확산 모델의 크기를 늘리는 것보다 샘플의 충실도와 이미지-텍스트 정렬이 더 크게 향상됩니다. Imagen은 COCO 데이터셋에서 7.27의 새로운 최첨단 FID 점수를 달성했으며, COCO에서 훈련하지 않고도 인간 평가자들이 Imagen 샘플을 COCO 데이터 자체와 동등한 수준으로 이미지-텍스트 정렬이 뛰어나다고 평가합니다. 텍스트-이미지 모델을 더 깊이 평가하기 위해 DrawBench라는 포괄적이고 도전적인 벤치마크를 소개합니다. DrawBench를 통해 VQ-GAN+CLIP, Latent Diffusion Models, DALL-E 2를 포함한 최근 방법들과 Imagen을 비교하고, 인간 평가자들이 샘플 품질과 이미지-텍스트 정렬 측면에서 다른 모델보다 Imagen을 선호한다는 것을 발견했습니다. 결과에 대한 개요는 https://imagen.research.google/에서 확인할 수 있습니다.

### - MT-Bench와 Chatbot Arena를 통한 LLM-as-a-judge 평가

**카테고리**: NLP, Alignment | **upvotes**: 43 | [arXiv](https://arxiv.org/abs/2306.05685)

> 강력한 LLM을 심판으로 사용하여 채팅 보조 도구를 평가하고 인간의 선호와 일치시킵니다.

**핵심 기여**:
- 대형 언어 모델 평가를 위한 LLM-as-a-judge 개념을 도입합니다.
- LLM 평가와 인간의 선호를 일치시키기 위한 벤치마크로 MT-bench와 Chatbot Arena를 제안합니다.
- LLM 심판과 인간의 선호가 80% 이상의 일치를 보임을 입증합니다.

**초록**:

대형 언어 모델(LLM) 기반의 채팅 보조 도구를 평가하는 것은 그들의 광범위한 능력과 기존 벤치마크가 인간의 선호를 측정하기에 충분하지 않기 때문에 어렵습니다. 이를 해결하기 위해 강력한 LLM을 심판으로 사용하여 보다 개방형 질문에 대해 이러한 모델을 평가하는 방법을 탐구합니다. LLM-as-a-judge의 사용 및 한계, 예를 들어 위치 및 장황함 편향과 제한된 추론 능력을 조사하고, 일부를 해결하기 위한 솔루션을 제안합니다. 그런 다음 MT-bench라는 다중 턴 질문 세트와 Chatbot Arena라는 크라우드소싱 배틀 플랫폼을 도입하여 LLM 심판과 인간의 선호 간의 일치를 검증합니다. 우리의 결과는 GPT-4와 같은 강력한 LLM 심판이 통제된 환경과 크라우드소싱된 인간의 선호 모두와 잘 일치하여 80% 이상의 일치를 달성함을 보여줍니다. 따라서 LLM-as-a-judge는 인간의 선호를 근사하는 확장 가능하고 설명 가능한 방법입니다. 또한, 우리의 벤치마크와 전통적인 벤치마크가 LLaMA/Vicuna의 여러 변형을 평가함으로써 서로를 보완함을 보여줍니다. 우리는 80개의 MT-bench 질문, 3천 개의 전문가 투표, Chatbot Arena에서의 3만 개의 인간 선호 대화를 공개할 예정입니다.
