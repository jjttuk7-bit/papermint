### - AskChem: 화학 문헌 합성을 위한 주장 중심 인프라

**카테고리**: NLP, Agent | **upvotes**: 285 | [arXiv](https://arxiv.org/abs/2607.28618) | [Project](https://www.askchem.org)

> AskChem은 화학 문헌 합성을 개선하기 위해 주장 중심의 인프라를 제안합니다.

**핵심 기여**:
- 화학 문헌을 위한 주장 중심의 검색 시스템을 소개합니다.
- 논문을 출처가 명확한 원자적이고 유형화된 주장으로 변환합니다.
- AI 에이전트를 위한 웹 인터페이스와 API 접근을 제공합니다.

**초록**:

화학 문헌 합성은 종종 여러 출판물에 흩어져 있는 특정 발견을 조합해야 하지만, 기존의 문헌 검색 시스템은 주로 순위가 매겨진 문서 목록만 반환합니다. 그 결과 과학자와 AI 에이전트는 관련 정보를 찾아내고, 출처를 확인하며, 여러 논문에서 답을 수작업으로 조합해야 합니다. 우리는 AskChem을 소개합니다. 이는 논문 단위가 아닌 출처를 가진 주장 단위로 검색하는 주장 중심 인프라입니다. 각 논문은 출처 DOI와 인용문 또는 명시적 증거 위치로 연결된 원자적이고 유형화된 주장으로 변환됩니다. 이 공유 주장 저장소 위에서 AskChem은 검색과 합성을 위한 보완 구조를 제공합니다. 계층적 검색과 탐색을 위한 안정화된 분류 체계, 주장 간 관계를 연결하는 증거 그래프, 과학 원칙 아래 색인된 논문을 배치하는 탐색적 살아있는 분류 체계가 포함됩니다. 현재 AskChem은 147,000개의 논문에서 240만 개의 주장을 색인화하고 있으며, 웹 인터페이스와 REST, SDK, MCP 접근을 제공합니다. AskChem-Bench에서 GPT-5.5 리더를 AskChem에 기반하여 사용하면 검색 없이 88.3%에 비해 100%의 DOI 해결 가능성을 보이며, 테스트된 다섯 시스템 중 가장 높은 인용 밀도를 기록합니다. AskChem은 https://askchem.org에서 사용할 수 있습니다.

### - Qwen-UI-Agent 기술 보고서: 차세대 실세계 중심 기반 GUI 에이전트를 향하여

**카테고리**: Agent, RL, Multimodal | **upvotes**: 268 | [arXiv](https://arxiv.org/abs/2607.28227) | [Project](https://tongyi-mai.github.io/Qwen-UI-Agent/)

> Qwen-UI-Agent는 GUI와 CLI 상호작용을 통합하여 실세계 중심의 GUI 에이전트를 발전시킵니다.

**핵심 기여**:
- 모바일, 컴퓨터, 웹, DeepSearch 환경에서 실세계 응용을 위한 기반 GUI 에이전트 Qwen-UI-Agent를 소개합니다.
- GUI 작업과 CLI 실행을 통합한 통합 액션 공간을 통해 매끄러운 작업 실행을 제공합니다.
- AutoResearch 스타일 데이터 플라이휠을 사용하여 반복적 작업 및 환경 구성, 실패 진단, 계획을 수행합니다.

**초록**:

GUI 에이전트는 기존 디지털 장치에서 범용 실행자가 될 잠재력을 가지고 있습니다. 이를 실세계에서 사용하기 위해, 우리는 실제 장치에서 신뢰성 있게 작동하고, 플랫폼을 넘나드는 워크플로우를 실행하며, GUI 상호작용과 CLI 실행을 결합하고, 장기 작업을 완료하며, 유용한 서비스를 능동적으로 시작하고, 최소한의 인간 노력으로 능력을 자율적으로 향상시키는 에이전트를 상상합니다. 이러한 비전에 따라, 우리는 모바일, 컴퓨터 사용, 웹, DeepSearch 환경을 아우르는 실세계 중심 기반 GUI 에이전트인 Qwen-UI-Agent를 제시합니다. Qwen-UI-Agent는 다양한 샌드박스 환경과 대규모 실제 장치 모바일 런타임을 결합합니다. 통합된 액션 공간은 GUI 작업과 CLI 실행을 결합하고 단일 모델 턴에서 일괄적 액션을 생성합니다. AutoResearch 스타일 데이터 플라이휠은 에이전트를 사용하여 작업과 환경을 구성하고, 실패를 진단하며, 후속 반복을 계획합니다. 온라인 RL은 100턴을 초과하는 경로에서의 훈련을 지원하며, 10,000개 이상의 동시 환경이 롤아웃을 가속화합니다. 경량 하니스 레이어는 모바일과 컴퓨터 전반에 걸쳐 능동적인 서비스 시작과 상태 기반 워크플로우를 지원합니다. 다양한 평가에서 Qwen-UI-Agent는 모바일 사용 벤치마크에서 최첨단 성능을 설정하면서 Opus 4.8, Gemini 3.1 Pro, GPT-5.6 Sol을 포함한 최전선 모델에 대해 컴퓨터 및 브라우저 사용 작업에서 경쟁력 있는 성능을 제공합니다. 모바일 사용에서는 MobileWorld에서 82.1%, MobileWorld-Real에서 92.2%, AndroidDaily에서 97.5%를 달성합니다. 컴퓨터 사용에서는 OSWorld-Verified에서 79.5%, OSWorld-v2에서 40.0%의 부분 진행 점수를 달성합니다. 브라우저 사용 및 GUI 그라운딩에서는 WebArena에서 73.6%, ScreenSpot-Pro에서 81.5%를 달성합니다.

### - Metis: 메모리 기반 모델

**카테고리**: Agent, Efficiency | **upvotes**: 242 | [arXiv](https://arxiv.org/abs/2607.26760)

> AI 에이전트에 네이티브 메모리 기능을 제공하는 메모리 기반 모델 Metis를 제안합니다.

**핵심 기여**:
- 네이티브 메모리 기능을 갖춘 메모리 기반 모델 개념을 도입합니다.
- 기초 모델에 네이티브 메모리 상태를 통합한 새로운 아키텍처 Metis를 제안합니다.
- 광범위한 실험을 통해 네이티브 메모리의 효율성과 최적화 이점을 입증합니다.

**초록**:

최근 AI 에이전트의 발전으로 인해 기초 모델에 본래의 기능이 내재되고 있습니다. 이는 멀티모달 기초 모델과 대규모 추론 모델의 발전으로 이어졌습니다. 그러나 에이전트 메모리는 여전히 주로 외부 모듈을 통해 구현되며, 본래의 메모리 기능은 거의 탐구되지 않았습니다. 본 논문에서는 메모리 기반 모델을 도입하여 기초 모델에 본래의 메모리 기능을 부여하는 방향으로 첫 발을 내딛습니다. 본래의 메모리를 두 가지 관점에서 형식화합니다: 백본 내에서 지속적이고 동적으로 진화하는 메모리 상태와, 모델 계산을 통해 정보를 자율적으로 저장하고 활용하는 본래의 메모리 절차입니다. 본래의 메모리는 아키텍처, 종단 간 최적화, 효율성에서 이점을 제공합니다. 이러한 형식화에 기반하여 Metis를 제안합니다. Metis는 기초 모델에 본래의 메모리 상태를 장착하는 새로운 아키텍처를 도입하여, 과거 정보를 모델에 압축하고 메모리 어텐션을 통해 접근할 수 있게 합니다. 대규모 메모리 특화 학습 데이터를 구축하고, 중간 학습을 통해 이러한 본래의 메모리 절차를 획득하기 위한 여러 최적화 목표를 도입합니다. Metis의 온라인 메모리 유지 관리는 그라디언트 없이 이루어지며, 메모리 업데이트는 단지 순방향 패스만 필요합니다. 추론 시 모든 학습된 모델 가중치는 동결된 상태로 유지되며, 본래의 메모리 상태는 표준 순방향 계산을 통해 자율적으로 변환됩니다. 광범위한 실험을 통해 Metis가 본래의 메모리 기능을 발휘함을 보여주고, 그 강점, 제한점 및 행동에 대한 상세한 분석을 제공합니다. 메모리 기반 모델에 대한 미래 연구를 촉진하기 위해 프로젝트와 모델 체크포인트를 공개합니다.

### - Frontis-MA1: 기계 학습 엔지니어링에서 재귀적 자기 개선을 위한 AI4AI 모델 훈련

**카테고리**: Agent, RL | **upvotes**: 157 | [arXiv](https://arxiv.org/abs/2607.28568) | [Project](https://frontisai.github.io/OpenRSI/)

> 기계 학습 엔지니어링에서 재귀적 자기 개선을 위한 OpenMLE와 Frontis-MA1을 소개합니다.

**핵심 기여**:
- 재귀적 자기 개선 연구를 위한 전체 스택 시스템 OpenMLE를 소개합니다.
- 실행 기반 SFT와 RL을 사용하여 메타 진화 에이전트 Frontis-MA1을 훈련합니다.
- MLE-Bench Lite와 NatureBench Lite에서 성능 향상을 입증합니다.

**초록**:

재귀적 자기 개선(RSI)은 AI 시스템이 AI 구축 과정을 개선하는 것을 요구합니다. 기계 학습 엔지니어링(MLE)은 이 능력을 연구할 수 있는 구체적이고 실행 가능한 테스트베드를 제공합니다. 우리는 MLE에서 RSI 연구를 위한 개방형 전체 스택 시스템 OpenMLE를 소개합니다. 이는 실행 피드백이 있는 검증 가능한 작업 환경(OpenMLE-Gym), 연산자 학습(OpenMLE-RL), 장기 탐색(OpenMLE-Evo)을 포함합니다. 이 스택에서 우리는 MLE를 위한 메타 진화 에이전트로서 Frontis-MA1(35B)을 후속 훈련합니다. 이는 네 가지 원자적 프로그램 진화 연산자(Draft, Improve, Debug, Crossover)를 중심으로 훈련과 추론을 정렬합니다. 동일한 연산자는 모든 평가 기준에 대한 데이터 중복 제거 후 실행 기반 SFT와 RL을 통해 훈련되고, 단일 루프에서 학습과 진화를 결합하여 장기 탐색으로 구성됩니다. MLE-Bench Lite에서 하나의 RTX 4090에 대해 작업당 12시간 예산으로, Frontis-MA1(35B)은 OpenMLE-Evo로 기본 모델에서 메달 평균을 39.39%에서 60.61%로 개선하고, OpenMLE-Evo-Max(벤치마크 독립 경험 사전과 비동기 탐색)로 71.21%에 도달하여 GPT-5.5 + Codex를 초과하고 GPT-5.6 Sol 및 2.8T Kimi K3에 근접합니다. 보류된 NatureBench Lite에서는 두 구성 요소가 전이됩니다. 프레임워크를 고정하고 훈련된 모델을 교체하면 Match-SOTA가 50%에서 70%로 상승하고, 모델을 고정하고 OpenMLE-Evo를 교체하면 20%에서 50%로 상승합니다. 우리는 재현 가능한 RSI를 향한 실행 가능한 AI4AI 연구를 가능하게 하기 위해 모델 가중치와 전체 OpenMLE 스택을 공개합니다. 코드: https://github.com/FrontisAI/OpenRSI

### - PhiZero: 물리적 언어를 중심으로 구축된 세계 모델

**카테고리**: Multimodal, Video | **upvotes**: 150 | [arXiv](https://arxiv.org/abs/2607.28624) | [Project](https://phi-zero.github.io/)

> PhiZero는 물리적 언어를 사용하여 세계의 변화를 명시적으로 추론하는 물리적 세계 모델을 제안합니다.

**핵심 기여**:
- 상태 전이를 추론하기 위해 물리적 언어를 사용하는 세계 모델 PhiZero를 소개했습니다.
- 비디오 예측에서 추론과 렌더링을 분리하는 reason-then-render 패러다임을 구현했습니다.
- 현실적이고 상호작용적인 세계 모델링 및 제로샷 모션 전이에 대한 모델의 능력을 입증했습니다.

**초록**:

PhiZero는 물리적 언어를 중심으로 구축된 물리적 세계 모델입니다. 기존의 물리적 세계 모델은 일반적으로 픽셀 공간에서 직접 미래 비디오를 예측하여, 고차원 시각 예측기 내에 암묵적으로 세계 역학을 남겨둡니다. 인간이 시각적 경험에서 예측 구조를 추상화하고 이를 자연 언어로 명시적으로 조직하는 능력에 영감을 받아, 우리는 야생 비디오에서 자가 지도 학습을 통해 물리적 언어를 배우고 이를 사용하여 물리적 세계가 어떻게 진화하는지를 명시적으로 추론합니다. 이에 따라, PhiZero는 reason-then-render 패러다임을 채택합니다: 먼저 물리적 언어 시퀀스로 미래 세계의 진화를 추론한 후, 추론된 전이를 비디오로 렌더링합니다. 생성 및 이해 벤치마크 전반에 걸친 광범위한 실험은 PhiZero가 물리적으로 일관된 세계 진화를 모델링할 수 있는 능력을 검증합니다. 또한 현실적이고 상호작용적인 세계 모델링, 세밀한 행동 조건부 시뮬레이션, 제로샷 모션 전이에 대한 잠재력을 보여줍니다.

### - 빠른 Transformer 디코딩: 하나의 쓰기 헤드만 필요합니다

**카테고리**: NLP, Efficiency | **upvotes**: 9 | [arXiv](https://arxiv.org/abs/1911.02150)

> Transformer 디코딩에서 메모리 대역폭을 줄이기 위해 멀티 쿼리 어텐션 메커니즘을 제안합니다.

**핵심 기여**:
- 키와 값을 헤드 간에 공유하는 멀티 쿼리 어텐션을 도입했습니다.
- 점진적 디코딩의 메모리 대역폭 요구 사항을 줄였습니다.
- 품질 저하가 거의 없이 디코딩 속도를 향상시켰습니다.

**초록**:

Transformer 신경망 모델에서 사용되는 멀티 헤드 어텐션 레이어는 RNN에 대한 강력한 대안으로, 시퀀스 내외의 정보 이동에 효과적입니다. 이러한 레이어의 학습은 일반적으로 시퀀스 길이 전체에 걸쳐 병렬화가 가능하여 빠르고 간단하지만, 병렬화가 불가능한 점진적 추론에서는 큰 '키'와 '값' 텐서를 반복적으로 로드해야 하는 메모리 대역폭 비용 때문에 종종 느립니다. 우리는 키와 값을 모든 다른 어텐션 '헤드'에서 공유하는 멀티 쿼리 어텐션이라는 변형을 제안하며, 이는 이러한 텐서의 크기를 크게 줄이고 점진적 디코딩의 메모리 대역폭 요구 사항을 줄입니다. 실험을 통해 결과 모델이 디코딩 속도가 훨씬 빠르며, 기본 모델에 비해 품질 저하가 미미하다는 것을 확인했습니다.

### - 2020년대의 ConvNet

**카테고리**: CV, Efficiency | **upvotes**: 2 | [arXiv](https://arxiv.org/abs/2201.03545)

> ConvNeXt라는 순수 ConvNet 모델을 제안하여 Vision Transformer와 성능 및 확장성에서 경쟁합니다.

**핵심 기여**:
- ResNet을 Vision Transformer 설계 방향으로 현대화한 순수 ConvNet 모델인 ConvNeXt를 소개합니다.
- ConvNeXt 모델이 ImageNet에서 87.8%의 top-1 정확도를 달성하고, COCO 탐지 및 ADE20K 세분화에서 Swin Transformer를 능가함을 보여줍니다.
- ConvNet의 설계 공간을 탐색하고 Transformer와의 성능 차이에 기여하는 주요 요소를 식별합니다.

**초록**:

시각 인식의 'Roaring 20s'는 Vision Transformer (ViT)의 도입으로 시작되었으며, 이는 빠르게 ConvNet을 대체하여 이미지 분류 모델의 최신 상태가 되었습니다. 그러나 일반적인 컴퓨터 비전 작업, 예를 들어 객체 탐지와 의미론적 세분화에 적용할 때 기본 ViT는 어려움을 겪습니다. 이러한 문제를 해결하기 위해 계층적 Transformer (예: Swin Transformer)는 ConvNet의 여러 사전 지식을 재도입하여 Transformer가 일반적인 비전 백본으로 실용적으로 사용 가능하게 했고, 다양한 비전 작업에서 뛰어난 성능을 보여주었습니다. 그러나 이러한 하이브리드 접근법의 효과는 여전히 주로 Transformer의 고유한 우수성에 기인하며, 컨볼루션의 본질적 귀납적 편향은 아닙니다. 본 연구에서는 디자인 공간을 재검토하고 순수 ConvNet이 달성할 수 있는 한계를 테스트합니다. 표준 ResNet을 Vision Transformer의 설계 방향으로 점진적으로 '현대화'하면서 성능 차이에 기여하는 여러 핵심 요소를 발견합니다. 이러한 탐색의 결과로 순수 ConvNet 모델의 가족인 ConvNeXt가 탄생했습니다. ConvNeXt는 표준 ConvNet 모듈로만 구성되어 있으며, 정확도와 확장성 면에서 Transformer와 경쟁할 수 있으며, ImageNet에서 87.8%의 top-1 정확도를 달성하고 COCO 탐지 및 ADE20K 세분화에서 Swin Transformer를 능가하면서 표준 ConvNet의 단순성과 효율성을 유지합니다.

### - SimCSE: 문장 임베딩의 간단한 대조 학습

**카테고리**: NLP | **upvotes**: 0 | [arXiv](https://arxiv.org/abs/2104.08821)

> SimCSE라는 간단한 대조 학습 방법을 제안하여 문장 임베딩을 개선합니다.

**핵심 기여**:
- SimCSE라는 간단하지만 효과적인 문장 임베딩을 위한 대조 학습 프레임워크를 제안합니다.
- 드롭아웃이 비지도 학습에서 최소한의 데이터 증강 역할을 할 수 있음을 입증합니다.
- 지도 대조 학습에 자연어 추론 데이터셋을 통합하여 임베딩 품질을 향상시킵니다.

**초록**:

이 논문은 SimCSE라는 간단한 대조 학습 프레임워크를 소개합니다. 이는 문장 임베딩의 최신 성능을 크게 향상시킵니다. 먼저 비지도 접근법을 설명합니다. 입력 문장을 대조 목표로 스스로 예측하며, 표준 드롭아웃만을 잡음으로 사용합니다. 이 간단한 방법은 놀랍도록 잘 작동하여 이전의 지도 방법과 동등한 성능을 보입니다. 드롭아웃이 최소한의 데이터 증강 역할을 하며, 이를 제거하면 표현 붕괴가 발생함을 발견했습니다. 그런 다음, 자연어 추론 데이터셋의 주석된 쌍을 대조 학습 프레임워크에 통합하여 '포함' 쌍을 긍정적으로, '모순' 쌍을 어려운 부정적으로 사용합니다. 표준 의미 텍스트 유사성(STS) 작업에서 SimCSE를 평가했으며, BERT base를 사용한 비지도 및 지도 모델이 각각 76.3%와 81.6%의 스피어만 상관을 달성했습니다. 이는 이전 최고 결과보다 각각 4.2%와 2.2% 향상된 것입니다. 또한, 대조 학습 목표가 사전 학습된 임베딩의 비등방성 공간을 더 균일하게 정규화하고, 지도 신호가 제공될 때 긍정 쌍을 더 잘 정렬함을 이론적, 경험적으로 보여줍니다.
