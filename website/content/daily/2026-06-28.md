# 2026-06-28 논문 요약
### - FlashAttention: IO 인식을 통한 빠르고 메모리 효율적인 정확한 어텐션

**카테고리**: Efficiency, NLP | **upvotes**: 15 | [arXiv](https://arxiv.org/abs/2205.14135)

> FlashAttention은 IO 인식 정확한 어텐션 알고리즘을 도입하여 긴 시퀀스에서 Transformer의 속도를 높입니다.

**핵심 기여**:
- 메모리 읽기/쓰기 최적화를 위해 타일링을 활용한 IO 인식 정확한 어텐션 알고리즘 FlashAttention을 제안합니다.
- FlashAttention이 HBM 접근을 줄이고 다양한 SRAM 크기에서 최적 성능을 보임을 입증했습니다.
- FlashAttention을 블록 희소 어텐션으로 확장하여 기존 근사 방법보다 빠른 성능을 달성합니다.

**초록**:

Transformer는 긴 시퀀스에서 느리고 메모리 소모가 큽니다. 이는 자기 어텐션의 시간 및 메모리 복잡도가 시퀀스 길이에 따라 제곱으로 증가하기 때문입니다. 근사 어텐션 방법은 모델 품질을 희생하여 계산 복잡도를 줄이려 했지만, 실제 속도 향상은 이루지 못했습니다. 우리는 어텐션 알고리즘이 GPU 메모리 간 읽기/쓰기를 고려하는 IO 인식을 해야 한다고 주장합니다. 우리는 GPU 고대역폭 메모리(HBM)와 GPU 온칩 SRAM 간 메모리 읽기/쓰기 횟수를 줄이기 위해 타일링을 사용하는 IO 인식 정확한 어텐션 알고리즘인 FlashAttention을 제안합니다. FlashAttention의 IO 복잡도를 분석하여 표준 어텐션보다 적은 HBM 접근을 필요로 하고, 다양한 SRAM 크기에서 최적임을 보입니다. 또한, FlashAttention을 블록 희소 어텐션으로 확장하여 기존 근사 어텐션 방법보다 빠른 근사 어텐션 알고리즘을 제공합니다. FlashAttention은 기존 기준보다 빠르게 Transformer를 학습시킵니다: BERT-large(시퀀스 길이 512)에서는 MLPerf 1.1 학습 속도 기록 대비 15%의 엔드 투 엔드 실제 속도 향상을, GPT-2(시퀀스 길이 1K)에서는 3배의 속도 향상을, Long-range arena(시퀀스 길이 1K-4K)에서는 2.4배의 속도 향상을 이룹니다. FlashAttention과 블록 희소 FlashAttention은 Transformer에서 더 긴 문맥을 가능하게 하여 더 높은 품질의 모델을 제공합니다(GPT-2에서 0.7 더 나은 혼란도, 장문 분류에서 6.4 포인트 상승). Path-X(시퀀스 길이 16K, 61.4% 정확도) 및 Path-256(시퀀스 길이 64K, 63.1% 정확도) 도전에서 우연보다 나은 성능을 달성한 최초의 Transformer를 가능하게 합니다.

### - CLIP 임베딩을 활용한 계층적 텍스트 조건부 이미지 생성

**카테고리**: CV, Multimodal | **upvotes**: 3 | [arXiv](https://arxiv.org/abs/2204.06125)

> 텍스트 조건부 이미지 생성을 위해 CLIP 임베딩을 활용하는 2단계 모델을 제안합니다.

**핵심 기여**:
- 텍스트 캡션으로부터 CLIP 이미지 임베딩을 생성하는 사전 모델을 제안합니다.
- 사진 실사성과 캡션 유사성의 최소 손실로 이미지 다양성을 개선했습니다.
- CLIP의 공동 임베딩 공간을 활용하여 제로샷 언어 기반 이미지 조작이 가능합니다.

**초록**:

CLIP과 같은 대조 모델은 이미지의 의미와 스타일을 포착하는 강력한 표현을 학습하는 것으로 나타났습니다. 이러한 표현을 이미지 생성에 활용하기 위해, 우리는 두 단계 모델을 제안합니다: 텍스트 캡션을 주어졌을 때 CLIP 이미지 임베딩을 생성하는 사전 모델과 이미지 임베딩을 조건으로 이미지를 생성하는 디코더입니다. 명시적으로 이미지 표현을 생성하면 사진 실사성과 캡션 유사성의 최소 손실로 이미지 다양성을 개선할 수 있음을 보여줍니다. 이미지 표현을 조건으로 하는 우리 디코더는 이미지의 의미와 스타일을 보존하면서도 이미지 표현에 없는 비본질적인 세부사항을 다양하게 변형할 수 있습니다. 또한, CLIP의 공동 임베딩 공간은 제로샷 방식으로 언어 기반 이미지 조작을 가능하게 합니다. 우리는 디코더에 확산 모델을 사용하고, 사전 모델에는 오토레그레시브 모델과 확산 모델 모두를 실험하여 후자가 계산적으로 더 효율적이고 더 높은 품질의 샘플을 생성함을 발견했습니다.

### - 자체 피드백을 통한 반복적 개선: Self-Refine

**카테고리**: NLP, Efficiency | **upvotes**: 2 | [arXiv](https://arxiv.org/abs/2303.17651)

> 자체 피드백을 통해 LLM 출력을 개선하는 Self-Refine 방법을 제안합니다.

**핵심 기여**:
- 자체 피드백을 활용한 LLM 출력의 반복적 개선 방법인 Self-Refine을 소개합니다.
- Self-Refine이 다양한 작업에서 평균 약 20%의 성능 향상을 가져옴을 입증합니다.
- 최신 LLM인 GPT-4도 추가 훈련 없이 테스트 시 성능을 더 향상시킬 수 있음을 보여줍니다.

**초록**:

대형 언어 모델(LLM)은 처음 시도에서 항상 최상의 출력을 생성하지는 않습니다. 인간이 글을 다듬는 방식에 영감을 받아, 우리는 LLM의 초기 출력을 반복적인 피드백과 개선을 통해 향상시키는 Self-Refine을 소개합니다. 이 방법은 LLM을 사용하여 초기 출력을 생성한 후, 동일한 LLM이 자신의 출력에 대한 피드백을 제공하고 이를 사용하여 스스로를 반복적으로 개선하는 것입니다. Self-Refine은 감독 학습 데이터, 추가 훈련 또는 강화 학습을 필요로 하지 않으며, 하나의 LLM을 생성자, 개선자 및 피드백 제공자로 사용합니다. 우리는 Self-Refine을 대화 응답 생성부터 수학적 추론에 이르는 7가지 다양한 작업에서 최신 LLM(GPT-3.5, ChatGPT, GPT-4)을 사용하여 평가했습니다. 평가한 모든 작업에서 Self-Refine으로 생성된 출력은 동일한 LLM을 사용한 기존의 단일 단계 생성보다 인간과 자동 메트릭에 의해 선호되었으며, 작업 성능이 평균 약 20% 절대적으로 향상되었습니다. 우리의 연구는 GPT-4와 같은 최신 LLM도 간단하고 독립적인 접근 방식을 사용하여 테스트 시 더욱 향상될 수 있음을 보여줍니다.
