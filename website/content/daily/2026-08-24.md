# 2026-08-24 논문 요약
### - 확률 미분 방정식을 통한 점수 기반 생성 모델링

**카테고리**: Theory | **upvotes**: 2 | [arXiv](https://arxiv.org/abs/2011.13456)

> 노이즈를 이용해 데이터 분포를 변환하는 점수 기반 생성 모델링을 제안합니다.

**핵심 기여**:
- 데이터 분포 변환을 위한 확률 미분 방정식 (SDE) 프레임워크를 도입합니다.
- 시간 의존적 그래디언트 필드, 즉 점수에 의존하는 역방향 SDE를 제안합니다.
- 역방향 SDE의 정확성을 높이기 위한 예측-보정 프레임워크를 개발합니다.

**초록**:

데이터에서 노이즈를 만드는 것은 쉽지만, 노이즈에서 데이터를 만드는 것은 생성 모델링입니다. 우리는 복잡한 데이터 분포를 노이즈를 천천히 주입하여 알려진 사전 분포로 부드럽게 변환하는 확률 미분 방정식(SDE)을 제시하고, 노이즈를 천천히 제거하여 사전 분포를 데이터 분포로 변환하는 역방향 SDE를 제안합니다. 특히, 역방향 SDE는 시간에 따라 변하는 그래디언트 필드(점수)에만 의존합니다. 점수 기반 생성 모델링의 발전을 활용하여 신경망으로 이러한 점수를 정확히 추정하고, 수치적 SDE 해석기를 사용하여 샘플을 생성할 수 있습니다. 이 프레임워크는 점수 기반 생성 모델링과 확산 확률 모델링의 기존 접근 방식을 포함하며, 새로운 샘플링 절차와 모델링 기능을 제공합니다. 특히, 이산화된 역방향 SDE의 진화를 수정하는 예측-보정 프레임워크를 도입합니다. 또한, SDE와 동일한 분포에서 샘플링하는 동등한 신경 ODE를 유도하여 정확한 가능도 계산과 샘플링 효율성을 향상시킵니다. 또한, 클래스 조건 생성, 이미지 인페인팅 및 색상화 실험을 통해 점수 기반 모델로 역문제를 해결하는 새로운 방법을 제공합니다. 여러 아키텍처 개선과 결합하여 CIFAR-10에서 Inception 점수 9.89와 FID 2.20으로 무조건적 이미지 생성에서 기록적인 성능을 달성하며, 점수 기반 생성 모델로 처음으로 1024 x 1024 이미지의 고충실도 생성을 시연합니다.

### - 자연어 감독으로부터 전이 가능한 시각 모델 학습

**카테고리**: CV, Multimodal | **upvotes**: 22 | [arXiv](https://arxiv.org/abs/2103.00020)

> 이미지에 대한 텍스트로부터 직접 학습하여 다양한 비전 작업에 제로샷 전이를 가능하게 합니다.

**핵심 기여**:
- 어떤 캡션이 어떤 이미지와 맞는지 예측하는 확장 가능한 사전 학습 과제를 도입합니다.
- 특정 작업에 대한 추가 학습 없이 다운스트림 작업에 제로샷 전이 능력을 입증합니다.
- ImageNet에서 ResNet-50의 정확도를 제로샷으로 달성하며, 학습 예제를 사용하지 않습니다.

**초록**:

최신 컴퓨터 비전 시스템은 고정된 사전 결정된 객체 카테고리를 예측하도록 학습됩니다. 이러한 제한된 감독 형태는 추가적인 라벨링 데이터가 필요하여 일반성과 사용성을 제한합니다. 이미지에 대한 원시 텍스트로부터 직접 학습하는 것은 훨씬 더 광범위한 감독 소스를 활용하는 유망한 대안입니다. 우리는 4억 개의 (이미지, 텍스트) 쌍으로 구성된 데이터셋에서 처음부터 SOTA 이미지 표현을 학습하는 효율적이고 확장 가능한 방법으로 어떤 캡션이 어떤 이미지와 맞는지를 예측하는 간단한 사전 학습 작업을 제시합니다. 사전 학습 후, 자연어를 사용하여 학습된 시각 개념을 참조하거나 새로운 개념을 설명함으로써 모델을 다운스트림 작업에 제로샷 전이할 수 있습니다. 이 접근법의 성능을 OCR, 비디오 내 행동 인식, 지리적 위치 지정, 다양한 종류의 세분화된 객체 분류와 같은 30개 이상의 기존 컴퓨터 비전 데이터셋에서 벤치마킹하여 연구합니다. 이 모델은 대부분의 작업에 비정상적으로 전이되며, 데이터셋 특정 학습이 필요 없이 종종 완전히 감독된 기준과 경쟁할 수 있습니다. 예를 들어, 우리는 ResNet-50의 원래 ImageNet 정확도를 제로샷으로 일치시키며, 1.28백만 개의 학습 예제를 사용할 필요가 없습니다. 우리는 우리의 코드와 사전 학습된 모델 가중치를 https://github.com/OpenAI/CLIP에서 공개합니다.

### - 인간 피드백을 활용한 강화 학습으로 유용하고 무해한 보조 도우미 훈련하기

**카테고리**: NLP, RL, Alignment | **upvotes**: 4 | [arXiv](https://arxiv.org/abs/2204.05862)

> 인간 피드백을 활용한 강화 학습으로 유용하고 무해한 언어 모델을 훈련하는 방법을 제안합니다.

**핵심 기여**:
- 선호 모델링과 인간 피드백 기반의 강화 학습을 적용하여 언어 모델을 미세 조정했습니다.
- 파이썬 코딩 및 요약과 같은 전문 기술 훈련과의 호환성을 입증했습니다.
- 효율적인 데이터셋과 모델 개선을 위한 반복 온라인 훈련 모드를 탐구했습니다.

**초록**:

선호 모델링과 인간 피드백 기반의 강화 학습(RLHF)을 적용하여 언어 모델을 유용하고 무해한 도우미로 미세 조정합니다. 이 정렬 훈련은 거의 모든 NLP 평가에서 성능을 향상시키며, 파이썬 코딩 및 요약과 같은 전문 기술 훈련과 완전히 호환됩니다. 우리는 선호 모델과 RL 정책을 매주 새로운 인간 피드백 데이터로 업데이트하는 반복 온라인 훈련 모드를 탐구하여 데이터셋과 모델을 효율적으로 개선합니다. 마지막으로, RLHF 훈련의 견고성을 조사하고, 정책과 초기화 사이의 KL 발산의 제곱근과 RL 보상 사이의 대략적인 선형 관계를 확인합니다. 주요 결과와 함께, 보정, 경쟁 목표 및 OOD 탐지 사용에 대한 주변 분석을 수행하고, 우리의 모델을 인간 작가와 비교하며, 최근 관련 작업에 나타나는 프롬프트를 사용한 모델 샘플을 제공합니다.
