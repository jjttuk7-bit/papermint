# 2026-07-28 논문 요약
### - DataPrep-Bench: LLM 기반 데이터 준비 벤치마크

**카테고리**: NLP, Agent, Alignment | **upvotes**: 42 | [arXiv](https://arxiv.org/abs/2607.20465) | [Project](https://datapreparationbench.github.io/)

> 이 논문은 데이터 준비 능력을 평가하기 위한 통합 벤치마크인 DataPrep-Bench를 제안합니다.

**핵심 기여**:
- LLM 기반 데이터 준비를 평가하기 위한 첫 번째 통합 벤치마크인 DataPrep-Bench를 소개합니다.
- Llama-3.1-8B 금융 분야에서 기준 성능을 약 20포인트 향상시키는 새로운 데이터 구축 방법을 제안합니다.
- 데이터 품질 평가를 위한 새로운 지표인 분포 정렬 점수(DAS)를 개발하여 강력한 모델 간 상관관계를 보입니다.

**초록**:

훈련 데이터의 품질은 대형 언어 모델(LLM)의 성능을 근본적으로 결정합니다. 그러나 LLM, 에이전트 및 데이터 중심 워크플로우가 훈련 데이터를 얼마나 잘 준비하는지 측정하는 통합된 벤치마크는 존재하지 않습니다. 우리는 LLM 기반 데이터 준비를 데이터 구축과 데이터 품질 평가라는 두 가지 상호 보완적 능력으로 봅니다. 데이터 구축은 원시 소스를 감독 학습 데이터로 변환하고, 데이터 품질 평가는 후보 데이터셋의 훈련 가치를 예측합니다. 여기서 '품질'은 표면적인 텍스트 속성보다는 다운스트림 학습 유용성을 의미합니다. 우리는 DataPrep-Bench를 소개합니다. 이는 여섯 개의 도메인과 여러 기본 모델에 걸쳐 공유된 다운스트림 중심 프로토콜 하에서 두 가지 능력을 공동으로 평가하는 최초의 통합 벤치마크입니다. 데이터 구축의 경우, 방법들은 동일한 원시 소스를 소비하고, Dolly-15k와 함께 기본 모델을 미세 조정하여 결과를 평가합니다. 이 트랙과 함께, Dolly 전용 기준을 Llama-3.1-8B 금융 분야에서 거의 20포인트 절대적으로 향상시키고, 지식 추출이 밀집된 도메인에서 강력한 에이전트 및 DataFlow 기반 방법과 경쟁할 수 있는 기술 안내 에이전트를 출시합니다. 데이터 품질 평가의 경우, 점수 함수는 공유된 후보 풀에서 다운스트림 성능과의 피어슨 상관관계로 평가됩니다. 우리는 후보 데이터셋과 도메인 프록시 간의 MMD를 사용하는 분포 기반 평가자인 DAS를 출시합니다. DAS는 여섯 개의 도메인 중 네 개에서 가장 강력한 모델 간 상관관계를 달성하며, 수학, 과학, 의료 분야에서 동시에 r > 0.70을 초과하는 유일한 지표로, 기존의 품질, 다양성 및 휴리스틱 기반 평가자를 능가합니다. DataPrep-Bench는 LLM 기반 데이터 준비의 두 가지 능력을 공동 목표로 측정하는 통합된 다운스트림 중심 프레임워크를 제공합니다.

### - 스킬 셀프 플레이: 공동 진화 스킬로 LLM 능력의 경계를 확장하기

**카테고리**: NLP, RL, Agent | **upvotes**: 30 | [arXiv](https://arxiv.org/abs/2607.22529)

> 과제 다양성과 검증 신뢰성을 균형 있게 조절하여 LLM의 능력을 향상시키는 Skill Self-Play 프레임워크를 제안합니다.

**핵심 기여**:
- 제안자, 해결자, 동적 스킬 컨트롤러로 구성된 Skill Self-Play (Skill-SP) 프레임워크를 소개합니다.
- Skill-SP는 과제 다양성과 검증 신뢰성을 효과적으로 조절하여 기존의 자기 진화 방법의 한계를 해결합니다.
- 도구 사용 및 추론 벤치마크에서 성능 향상을 보여주며 LLM 백본의 능력을 확장합니다.

**초록**:

LLM 훈련은 수동 설계 및 주석에서 상호작용 기반 자기 진화로 전환되고 있습니다. 그러나 기존의 자기 진화 방법은 과제 다양성과 검증 신뢰성 사이의 근본적인 딜레마에 직면합니다. 환경에 제한된 방법은 정확한 피드백을 얻지만 학습을 좁은 도메인에 제한하며, 개방형 자기 생성은 과제 공간을 확장하지만 신뢰할 수 있는 검증이 부족하여 오도된 보상이 훈련 루프를 오염시킬 수 있습니다. 우리는 에이전트 스킬을 이 긴장을 해결하는 강력한 중간 지점으로 식별합니다. 각 스킬은 특정 시나리오에서 깊고 검증 가능한 실행을 보장하고, 스킬 간의 동적 라우팅은 개방형 과제 다양성을 유지합니다. 이러한 통찰력을 활용하여, 우리는 제안자, 해결자, 동적 스킬 컨트롤러로 구성된 공동 진화 프레임워크인 Skill Self-Play (Skill-SP)를 소개합니다. 강화 학습 루프를 통해 조정된 이 구성 요소들은 연속적인 셀프 플레이 루프에서 공동 진화합니다. 제안자는 동적으로 샘플링된 스킬에 조건화된 도전 과제를 생성하고, 해결자는 후보 해결책을 탐색하여 능력의 경계를 확장하며, 스킬 컨트롤러는 실행 피드백을 수집하여 스킬 라이브러리를 업데이트하고 확장합니다. 이 상호작용적 공동 진화는 구조화된 검증과 개방형 탐색 사이의 격차를 효과적으로 메웁니다. 도구 사용 및 추론 벤치마크에 대한 실증적 평가에서 Skill-SP는 강력한 진화 엔진으로서, 유능한 백본의 성능 한계를 지속적으로 확장하며 초기에는 잘못 정렬된 모델에 놀라운 전환을 촉진합니다. 우리의 코드는 https://github.com/Qwen-Applications/skill-self-play에서 확인할 수 있습니다.

### - Molt: 에이전트 강화 학습을 위한 확장 가능한 PyTorch 기반 훈련 프레임워크

**카테고리**: RL, Efficiency, Agent | **upvotes**: 24 | [arXiv](https://arxiv.org/abs/2607.21653)

> Molt는 에이전트 강화 학습 연구를 간소화하는 확장 가능한 PyTorch 기반 프레임워크를 제안합니다.

**핵심 기여**:
- 에이전트 강화 학습에 특화된 PyTorch 기반 프레임워크를 소개합니다.
- 연구자와 AI 코딩 보조가 쉽게 이해할 수 있는 간결하고 깔끔한 코드베이스를 보장합니다.
- 완전 비동기 방식으로 최신 프레임워크와 통계적으로 유사한 성능을 유지합니다.

**초록**:

에이전트 강화 학습 연구는 알고리즘 수정, 새로운 추정기, 새로운 파이프라인 단계, 새로운 롤아웃 방식의 지속적 변화입니다. 주류 프레임워크에서는 이러한 변경이 트레이너, 분산 백엔드, 롤아웃 접착제의 여러 층을 통과합니다. Molt는 이러한 비용을 줄이기 위해 구축된 PyTorch 기반의 훈련 프레임워크입니다. 연구자가 전체 코드를 머리에 담을 수 있을 만큼 간결하고 깨끗하며, AI 코딩 보조가 전체를 읽고 이해할 수 있어 알고리즘 흐름을 처음부터 끝까지 추적하고 변경할 수 있습니다. 에이전트는 일반 프로그램이며, 비동기 루프가 다중 모달 및 전문가 혼합 정책을 훈련하면서 생성하지 않은 토큰에 대해 훈련하지 않습니다. 이로 인해 토큰, 정책 버전, 모델 의미론에서 일관성을 유지합니다. 간결함이 성능을 희생하지 않습니다. 완전 비동기 프로토콜에서 Molt는 최신 Megatron 기반 스택과 통계적으로 비교할 수 있습니다. Molt는 오픈 소스로 제공되며, https://github.com/NVIDIA-NeMo/labs-molt에서 레시피와 컨테이너를 제공합니다.

### - 원천 멀티모달 사전학습의 스케일링

**카테고리**: NLP, Multimodal, Efficiency | **upvotes**: 18 | [arXiv](https://arxiv.org/abs/2607.22043)

> 원천 멀티모달 사전학습의 최적 스케일링 법칙을 연구하여 교차 모달 통합을 강화합니다.

**핵심 기여**:
- 원천 멀티모달 사전학습에서 최소 목표 손실을 위한 예측 가능한 계산 법칙을 확립합니다.
- 언어와 멀티모달 목표에 대한 서로 다른 스케일링 행동을 식별합니다.
- 모델 크기, 토큰 수 및 데이터 혼합 구성에 대한 효율성 경계를 도출합니다.

**초록**:

대형 언어 모델(LLM)은 뛰어난 추론 능력을 보이지만, 텍스트에만 의존한 사전학습은 멀티모달 물리 세계의 인식을 제한합니다. 원천 멀티모달 사전학습은 멀티모달 입력으로 처음부터 모델을 학습하여 이러한 제한을 피하고, 깊은 교차 모달 통합을 이루며 전통적인 지연 융합 아키텍처의 최적화 비대칭성을 완화합니다. 이러한 장점에도 불구하고, 이 패러다임의 스케일링 특성은 체계적으로 특성화되지 않았습니다. 이 격차를 해결하기 위해, 우리는 고정된 계산 예산 하에서 트랜스포머 기반 비전-언어 모델을 학습하기 위한 최적의 모델 크기와 토큰 수를 조사합니다. 최소 목표 손실이 예측 가능한 계산 법칙을 따르는 반면, 계산 최적의 모델 크기와 토큰 수는 멱법칙으로 확장됨을 보여줍니다. 특히, 언어와 멀티모달 목표는 서로 다른 스케일링 행동을 보입니다. 언어 할당 법칙은 데이터 구성에 크게 영향을 받지 않으며, 멀티모달 데이터 비율에 상관없이 안정적인 언어 학습을 나타냅니다. 반면, 멀티모달 할당 법칙은 이 구성에 매우 민감합니다. 특히, 텍스트 중심의 혼합은 더 큰 모델 규모에서만 계산 효율적이 되어, 최적의 자원 할당을 더 큰 모델 용량으로 이동시킵니다. 또한, 데이터 구성의 계산 법칙과 할당 지수에 미치는 영향을 모델링하여, 모델 크기, 토큰 수 및 데이터 혼합의 정확한 구성을 지정하는 효율성 경계를 도출합니다. 다운스트림 평가에서는 원천 멀티모달 사전학습이 긍정적인 교차 모달 전이를 유도하여 순수 텍스트 공간 추론을 강화하고 강력한 멀티모달 인컨텍스트 학습을 가능하게 함을 보여줍니다. 요약하면, 이 실증적 연구는 멀티모달 기초 모델의 예측 가능한 스케일링을 위한 필수 토대를 마련합니다.

### - 에이전틱 컨텍스트 관리: 에이전트 메모리와 비용 문제를 수명 주기 및 아키텍처 문제로 해결

**카테고리**: NLP, Agent, Efficiency | **upvotes**: 17 | [arXiv](https://arxiv.org/abs/2607.21503) | [Project](https://maximem.ai/synap)

> 에이전트 메모리와 비용 문제를 수명 주기 및 아키텍처 문제로 접근하여 해결하는 에이전틱 컨텍스트 관리(ACM)를 제안합니다.

**핵심 기여**:
- 에이전틱 컨텍스트 관리(ACM)를 수명 주기 문제로 소개합니다.
- ACM을 아키텍팅, 인제스팅, 스코핑, 예상, 압축 및 통합의 5가지 기본 요소로 분해합니다.
- 참조 구현인 Maximem Synap을 제시하며, LongMemEval 및 LoCoMo 벤치마크에서 높은 점수를 달성했습니다.

**초록**:

생산 AI 에이전트의 실패는 주로 추론 능력 부족이 아닌, 대화 기록, 큰 프롬프트, 도구 정의 및 출력 관리 실패로 인해 발생합니다. 에이전트는 자신의 누적된 역사에 빠져들며, 회차마다 증가하는 토큰 비용을 지불하고, 대화 내외에서 회상이 누락됩니다. 기존의 대응은 이를 저장 및 검색 문제로 취급합니다. 우리는 이 프레임이 너무 좁다고 주장합니다. 에이전트가 기억할 것을 결정하고, 이를 추출 및 구조화하며, 데이터 유형별로 적절한 저장소를 선택하고, 출처를 보존하면서 통합 및 잊는 것, 현재 관련성을 결정하고, 다음에 필요한 것을 예측하며, 중요한 것을 잃지 않고 예산에 맞게 컨텍스트를 압축하는 것은 단순한 저장이 아닌 수명 주기입니다. 진지한 생산에서는 단일 사용자가 아닌 조직적 범위 계층에 걸쳐 작동합니다. 우리는 이를 에이전틱 컨텍스트 관리(ACM)라고 명명하고, 이를 아키텍팅, 인제스팅, 스코핑, 예상, 압축 및 통합의 다섯 가지 기본 요소로 분해합니다. 경제적 관점에서, 단순한 컨텍스트 누적은 대화 길이에 따라 토큰 비용이 제곱적으로 증가하며, 조잡한 요약은 정확성의 절벽을 대가로 선형 비용을 구매하지만, 검증된 압축만이 충실도를 유지하면서 선형 비용을 달성합니다. 우리는 다중 테넌트 서비스로 다섯 가지 기본 요소를 실현하는 참조 구현 Maximem Synap을 설명하며, 섹션 6에 자세히 설명된 구성에서 LongMemEval에서 92%, LoCoMo에서 93.2%를 보고합니다. 기존 벤치마크가 아직 포착하지 못한 차원인 대기 시간, 토큰 효율성, 컨텍스트 회전 저항, 결정을 내리는 수준 및 조직 수준의 컨텍스트의 최전선을 마무리합니다.

### - GLU 변형을 통한 Transformer 성능 개선

**카테고리**: NLP, Efficiency | **upvotes**: 5 | [arXiv](https://arxiv.org/abs/2002.05202)

> Gated Linear Units의 변형을 제안하여 Transformer 모델의 성능을 개선합니다.

**핵심 기여**:
- 전통적인 활성화 함수를 대체할 Gated Linear Units의 변형을 소개합니다.
- 이 GLU 변형을 사용하여 Transformer 모델의 성능 향상을 입증합니다.
- GLU에서 다양한 비선형 함수가 모델 품질에 미치는 영향을 분석합니다.

**초록**:

Gated Linear Units (arXiv:1612.08083)은 두 개의 선형 투영의 성분별 곱으로 구성되며, 이 중 하나는 시그모이드 함수를 통과합니다. 시그모이드 대신 다른 비선형(또는 선형) 함수를 사용하는 GLU 변형이 가능합니다. 이러한 변형을 Transformer (arXiv:1706.03762) 시퀀스-투-시퀀스 모델의 피드포워드 서브레이어에서 테스트하여, 일반적으로 사용되는 ReLU 또는 GELU 활성화보다 품질이 개선되는 일부 변형을 발견했습니다.

### - Squeeze-and-Excitation 네트워크

**카테고리**: CV, Efficiency | **upvotes**: 0 | [arXiv](https://arxiv.org/abs/1709.01507)

> 채널별 특징 반응을 적응적으로 재조정하여 CNN 성능을 향상시키는 Squeeze-and-Excitation Networks를 제안합니다.

**핵심 기여**:
- 채널 간 상호 의존성을 모델링하는 Squeeze-and-Excitation (SE) 블록을 도입했습니다.
- 기존 CNN에서 최소한의 계산 비용으로 성능을 크게 향상시켰습니다.
- ILSVRC 2017 분류에서 2.251%의 top-5 오류율로 1위를 달성했습니다.

**초록**:

합성곱 신경망(CNN)의 중심 구성 요소는 합성곱 연산자로, 각 층의 지역 수용 영역 내에서 공간 및 채널 정보를 융합하여 정보를 생성합니다. 기존 연구는 주로 공간적 요소를 강화하여 CNN의 표현력을 높이는 데 중점을 두었습니다. 본 연구에서는 채널 간 관계에 초점을 맞추어, 채널 간 상호 의존성을 명시적으로 모델링하여 채널별 특징 반응을 적응적으로 재조정하는 새로운 아키텍처 유닛인 'Squeeze-and-Excitation(SE) 블록'을 제안합니다. 이러한 블록을 쌓아 다양한 데이터셋에서 일반화 성능이 뛰어난 SENet 아키텍처를 구성할 수 있음을 보여줍니다. 또한, SE 블록이 기존 최첨단 CNN의 성능을 약간의 추가 계산 비용으로 크게 개선함을 입증합니다. Squeeze-and-Excitation 네트워크는 ILSVRC 2017 분류 제출에서 1위를 차지했으며, 2016년 우승작보다 약 25% 상대적 개선된 2.251%의 top-5 오류율을 기록했습니다. 모델과 코드는 https://github.com/hujie-frank/SENet에서 제공합니다.

### - DeBERTa: 분리된 어텐션을 통한 디코딩 강화 BERT

**카테고리**: NLP, Efficiency | **upvotes**: 3 | [arXiv](https://arxiv.org/abs/2006.03654)

> DeBERTa는 분리된 어텐션과 향상된 마스크 디코딩을 통해 NLP 모델 성능을 개선합니다.

**핵심 기여**:
- 내용과 위치 정보를 분리하는 어텐션 메커니즘을 도입했습니다.
- 절대 위치를 활용한 향상된 마스크 디코더로 마스크된 토큰 예측을 개선했습니다.
- 모델 일반화를 위해 가상 적대적 훈련을 적용했습니다.

**초록**:

최근 사전 훈련된 신경망 언어 모델의 발전은 많은 자연어 처리 작업의 성능을 크게 향상시켰습니다. 본 논문에서는 BERT와 RoBERTa 모델을 개선하기 위해 두 가지 새로운 기술을 사용하는 DeBERTa(분리된 어텐션을 통한 디코딩 강화 BERT)라는 새로운 모델 아키텍처를 제안합니다. 첫 번째는 분리된 어텐션 메커니즘으로, 각 단어를 내용과 위치를 각각 인코딩하는 두 벡터로 표현하며, 단어 간 어텐션 가중치는 내용과 상대적 위치에 대해 분리된 행렬을 사용하여 계산됩니다. 두 번째로, 향상된 마스크 디코더를 사용하여 모델 사전 훈련 시 마스크된 토큰을 예측하기 위해 디코딩 레이어에 절대 위치를 통합합니다. 추가적으로, 모델의 일반화를 향상시키기 위해 새로운 가상 적대적 훈련 방법을 사용합니다. 이러한 기술들이 모델 사전 훈련의 효율성과 자연어 이해(NLU) 및 자연어 생성(NLG) 다운스트림 작업의 성능을 크게 향상시킴을 보여줍니다. RoBERTa-Large와 비교하여, 절반의 훈련 데이터로 학습된 DeBERTa 모델은 다양한 NLP 작업에서 일관되게 더 나은 성능을 보이며, MNLI에서 +0.9%(90.2% 대 91.1%), SQuAD v2.0에서 +2.3%(88.4% 대 90.7%), RACE에서 +3.6%(83.2% 대 86.8%)의 개선을 달성했습니다. 특히, 48개의 Transformer 레이어와 15억 개의 파라미터로 구성된 더 큰 버전의 DeBERTa를 학습시킴으로써, 단일 DeBERTa 모델이 처음으로 SuperGLUE 벤치마크에서 인간 성능을 초과하는 매크로 평균 점수(89.9 대 89.8)를 달성했으며, 2021년 1월 6일 기준으로 앙상블 DeBERTa 모델이 인간 기준을 상당한 차이로 초과하여(90.3 대 89.8) SuperGLUE 리더보드의 최상위에 위치합니다.
