# 2026-08-20 논문 요약
### - 에이전트 스킬의 이해: 왜 작동하다가 작동하지 않는가

**카테고리**: NLP, Agent | **upvotes**: 139 | [arXiv](https://arxiv.org/abs/2608.14036) | [Project](https://zhiyuanjiang04.github.io/demystify-agent-skills)

> LLM 에이전트의 스킬이 언제, 왜 성공하거나 실패하는지를 조사하여 에이전트의 견고성을 향상시키는 통찰을 제공합니다.

**핵심 기여**:
- 스킬의 표현, 결과 주석, 검색 난이도, 프레임워크 간 견고성의 효과를 분리했습니다.
- 통제된 정량 실험과 쌍을 이루는 경로 분석을 결합한 대조 연구를 설계했습니다.
- 세 가지 상위 카테고리와 열두 가지 스킬 사용 모드의 분류 체계를 개발하여 절차적 고정이 주요 성공 요인임을 강조했습니다.

**초록**:

스킬은 지식의 구조적 패키지를 통해 추론 시 LLM 에이전트를 강화하는 실용적이고 효과적인 접근 방식으로 부상했습니다. 그러나 기존의 평가들은 주로 스킬이 집계된 작업 성공을 개선하는지 여부를 측정하는 데 그치며, 보다 근본적인 질문은 탐구되지 않았습니다: 스킬이 언제 도움이 되고, 왜 작동하며, 어디서 실패하는가? 다양한 벤치마크, 에이전트 하네스, LLM을 통한 통제된 실험을 통해 스킬의 표현, 결과 주석, 검색 난이도, 프레임워크 간 견고성의 효과를 분리했습니다. 이 질문에 더 답하기 위해 통제된 정량 실험과 쌍을 이루는 경로 분석을 결합한 대조 연구를 설계했습니다. 통제된 실험에서 8,135개의 시험 기록을 정규화하고 240개의 오픈 코드 기록에서 238개의 유효한 고유 레이블을 유지했습니다. 이러한 관찰을 세 가지 상위 카테고리와 열두 가지 스킬 사용 모드의 분류 체계로 통합했습니다: 스킬은 소음이 있는 경로가 실행을 안정화하는 절차적 고정이 될 때 작동합니다. 스킬은 일치하는 비교에서 워크플로 메모리를 6.06 포인트 향상시킵니다. 절차적 고정은 스킬 사례의 65.7%를 차지하며, 명시적 지식 주입은 4.5%에 불과하여 스킬은 누락된 사실을 주입하기보다는 행동을 안정화합니다. 검색은 별도의 병목 현상입니다: 풀의 크기가 5에서 100으로 증가함에 따라 실제 사용 정밀도는 29.6%에서 3.3%로 떨어집니다. 혼동 가능한 방해 요소는 오프라인 식별을 방해하지만, 다운스트림 성공은 안정적입니다; 정확한 진실 호출은 충분하지도 필요하지도 않습니다. 스킬은 취약한 가정, 호환되지 않는 컨텍스트 또는 불충분한 적응에서 실패합니다. 이러한 결과는 집계 성공률을 넘어 평가를 이동시키고 신뢰할 수 있는 자가 진화 에이전트를 안내합니다.

### - Agentic ESOpt: 최소한의 GPU 요구로 장기적 LLM 에이전트 미세 조정

**카테고리**: RL, Efficiency, Agent | **upvotes**: 91 | [arXiv](https://arxiv.org/abs/2608.17310) | [Project](https://zz1358m.github.io/Project-Agentic-ESOpt)

> 최소한의 GPU 자원으로 진화 전략을 활용해 장기적 LLM 에이전트를 미세 조정하는 Agentic ESOpt를 제안합니다.

**핵심 기여**:
- 진화 전략을 통해 장기적 LLM 에이전트를 미세 조정하는 Agentic ESOpt를 제안합니다.
- 진화 전략이 최소한의 GPU 메모리로 전체 파라미터 최적화를 가능하게 하여 대형 LLM을 미세 조정할 수 있음을 보여줍니다.
- 탐색-적응 균형을 개선하기 위해 섭동 규모에 대한 코사인 감쇠 일정을 도입합니다.

**초록**:

강화 학습 (RL)은 단일 턴 LLM 미세 조정에서 유망했습니다. 그러나 장기적 에이전트 추론은 점점 더 많은 분기 상호작용과 희소한 보상을 초래하며, RL의 여러 제한점을 드러냅니다: 무거운 역전파 기반 훈련 스택은 더 큰 LLM을 미세 조정하는 데 비실용적이며, 더 긴 수평선 경로는 RL에서 신용 할당을 상당히 어렵게 만듭니다. 본 논문은 진화 전략 (ES)이 장기적 LLM 에이전트를 미세 조정하는 데 더 나은 선택이 될 수 있음을 주장합니다. 에이전트 RL과 비교하여 ES는 세 가지 주요 장점을 제공합니다: 1) 모델 확장성: ES는 최소한의 추론 수준 GPU 메모리로 전체 파라미터 최적화를 가능하게 하여 대형 LLM을 미세 조정할 수 있게 합니다. 2) 유연성: 가벼운 블랙박스 피드백 인터페이스로 ES 미세 조정은 프롬프트 공간 진화 (예: 스킬 최적화 및 테스트 시 계산)와 쉽게 결합할 수 있습니다. 3) 장기적 확장성: ES는 수평선 전체에 보상을 분해하지 않고 경로 수준 파라미터 귀속을 수행하여 수평선 길이가 길어질수록 에이전트 RL보다 더 나은 확장성을 제공합니다. 이러한 통찰에 기반하여, 우리는 유연한 파라미터-컨텍스트 공동 진화를 위한 전체 파라미터 에이전트 미세 조정 프레임워크인 Agentic ESOpt를 제안합니다. 각 단계에서 Agentic ESOpt는 현재 LLM 파라미터 주변에서 섭동을 샘플링하고, 결과 에이전트를 보상으로 평가하며, 온라인 보상 가중 업데이트를 적용합니다. 탐색-적응 균형을 개선하기 위해 Agentic ESOpt는 섭동 스케일 σ의 코사인 감쇠 일정을 추가로 도입합니다. WebArena-Lite에서 Qwen-3.5-27B의 전체 파라미터 최적화는 No Skill 기준선을 6.69% 향상시킵니다. 테스트 시 자동 휴리스틱 설계에서 Agentic ESOpt는 온라인 프롬프트-파라미터 공동 진화를 수행하여 36개 설정 중 28개에서 일치하는 기준선을 개선합니다.

### - FreeToken: 대역폭 적응 실행을 통한 효율적인 엣지 네이티브 MoE 서비스

**카테고리**: Efficiency, Agent | **upvotes**: 59 | [arXiv](https://arxiv.org/abs/2608.16157) | [Project](https://www.flashml.ai/)

> FreeToken은 가용 자원에 맞춰 실행을 조정하여 개인 기계가 대규모 모델을 서비스할 수 있도록 하는 엣지 네이티브 MoE 서비스 시스템을 제안합니다.

**핵심 기여**:
- 로컬 하드웨어 자원에 적응하는 엣지 네이티브 MoE 서비스 시스템 FreeToken을 소개합니다.
- 모델 레이아웃, 전문가 상주 및 실행 전략을 공동 설계하여 엣지 하드웨어 활용을 최적화합니다.
- 노트북부터 게이밍 데스크탑까지 개인 기계에서 대규모 모델을 서비스할 수 있는 능력을 입증합니다.

**초록**:

최신 오픈 가중치 모델은 점점 더 많이 제공되고 있지만, 이를 서비스하기 위해서는 여전히 데이터센터 인프라가 필요하다고 가정합니다. FreeToken은 개인 기계를 작은 GPU가 아닌 통합된 탄력적 추론 플랫폼으로 취급하는 엣지 네이티브 MoE 서비스 시스템을 제안합니다. FreeToken은 로컬 AI의 두 가지 현실, 즉 에이전트 작업 부하가 지속적으로 실행 패턴을 변경하고, 엣지 하드웨어가 기계마다 균형이 다른 이질적인 자원을 노출한다는 점을 중심으로 모델 레이아웃과 로딩, 전문가 상주, CPU-GPU 실행, 에이전트 상태 재사용, 런타임 메모리 관리 등 전체 서비스 스택을 공동 설계합니다. 고정된 오프로드 전략에 얽매이지 않고, FreeToken은 실제로 사용 가능한 자원에 계산과 모델 상태를 지속적으로 매핑합니다. FreeToken은 8GB 노트북 GPU에서부터 단일 워크스테이션 GPU에 이르기까지 하드웨어 전반에 걸쳐 20개 이상의 MoE 모델과 실제 코딩 및 도구 사용 에이전트를 지원합니다. 더 중요한 것은, 노트북에서 35B 모델부터 게이밍 데스크탑에서 284B 모델, 단일 워크스테이션 GPU에서 753B GLM-5.2까지 실제적으로 제공할 수 있는 기계를 변화시킵니다. FreeToken은 오픈 가중치를 배포 가능한 로컬 소프트웨어로 전환하여 사용자가 이미 소유한 기계를 최첨단 지능을 위한 실용적인 플랫폼으로 만듭니다. 시스템은 flashml.ai에서 공개합니다.

### - ASI-Bench: 인공지능 초지능의 새벽

**카테고리**: Agent, Theory | **upvotes**: 52 | [arXiv](https://arxiv.org/abs/2608.17271) | [Project](https://asibench.apexin.ai/)

> ASI-Bench는 AI 시스템의 혁신적 탐구와 자율적 과학 수행 능력을 평가합니다.

**핵심 기여**:
- AI의 혁신적 탐구와 자율적 수행 능력을 평가하는 벤치마크, ASI-Bench를 소개합니다.
- ASI-Bench는 인간의 방법론적 지침을 점진적으로 줄여 AI의 독립적 연구 능력을 시험합니다.
- 11개 과학 분야에 걸친 60개의 연구 과제를 포함하며, 전문가 검토와 AI 지원 감사를 수행합니다.

**초록**:

인공지능 초지능 (ASI)은 기존 지식을 넘어 미지의 영역을 탐구하고 새로운 지식을 창출하며, 이를 검증 가능한 결과로 전환하는 것을 요구합니다. 하지만 현재 AI 시스템의 능력은 여전히 기존 인간 지식을 학습하고 압축하며 적용하는 데 크게 의존하고 있습니다. 이에 따라 기존 벤치마크는 주로 AI가 학습된 지식 기반으로 올바른 답을 생성할 수 있는지, 또는 광범위한 인간의 지침 하에 작업을 완료할 수 있는지를 테스트합니다. 따라서 우리는 AI 시스템의 혁신적 탐구와 자율적 과학 수행 능력을 일반 연구 분야에서 공동 평가하는 첫 번째 벤치마크인 ASI-Bench를 소개합니다. 또한 동일한 연구 프로젝트 내에서 인간의 방법론적 지침을 점진적으로 철회하여 AI가 스스로 어느 정도까지 진행할 수 있는지를 테스트하는 첫 번째 벤치마크입니다. 40명 이상의 전문가가 31,000시간 이상의 인간 시간을 들여 구축한 ASI-Bench는 11개 과학 분야에 걸친 60개의 프로젝트 수준의 연구 과제를 포함하며, AI가 독립적으로 방법을 선택하고 연구를 수행하며 검증 가능한 결과를 생성할 수 있는지를 테스트하기 위해 방법론적 지침을 점진적으로 줄입니다. 모든 과제는 전문가 검토, AI 지원 감사, 샌드박스 실행 및 점수 검증을 거칩니다. 18개의 최첨단 에이전트-모델 구성에서 평균 점수는 완전한 방법론적 지침 하에서 50.91에서 방법만 지정된 상태에서 29.10, 에이전트가 스스로 방법을 결정해야 할 때는 26.62로 급격히 감소합니다. 이 급격한 감소는 현재 시스템이 여전히 인간의 지침에 크게 의존하고 있으며, 독립적으로 프로젝트 수준의 과학 연구를 수행하는 데는 아직 멀었다는 것을 보여줍니다. ASI-Bench는 전 세계에 개방되어 있습니다. 연구자와 개발자들이 새로운 과제를 기여하고, 오늘날 AI의 한계를 도전하며, 인공지능 초지능을 향한 인류의 집단적 경로를 가속화하는 데 기여하기를 초대합니다: https://asibench.apexin.ai/submit.

### - Embodied-Navigator: 효율적인 내비게이션을 위한 지점, 사고, 기억 및 정렬

**카테고리**: Multimodal, RL, Efficiency | **upvotes**: 44 | [arXiv](https://arxiv.org/abs/2608.17512) | [Project](https://zju-omniai.github.io/Embodied-Navigator/)

> VLM을 2D 시각 능력에 맞추고 추론과 메모리를 최적화하여 효율적인 내비게이션을 위한 TAMP-Nav를 제안합니다.

**핵심 기여**:
- VLM의 2D 시각 능력에 맞춘 실행을 위해 Pixel-to-3D 액션 공식화를 도입합니다.
- 효율적인 메모리 관리를 위한 선택적 추론 및 앵커-경로 메모리 메커니즘을 제안합니다.
- 적응적 추론을 강화하기 위해 그룹 상대 정책 최적화를 통한 이중 정렬 패러다임을 설계합니다.

**초록**:

대규모 비전-언어 모델 (VLM)은 내비게이션 분야에서 큰 발전을 이루었지만, 직접적인 적용에는 어려움이 있습니다. 기존 방법들은 VLM을 2D 사전 학습과 맞지 않는 행동 공간으로 강제하고, 경직된 추론 일정과 비효율적인 메모리 관리가 문제입니다. 이러한 한계를 극복하기 위해, 우리는 효율적인 내비게이션을 위한 통합 프레임워크인 TAMP-Nav를 제안합니다. 먼저, 내비게이션을 2D 시각 프롬프트로 재구성하는 Pixel-to-3D 액션 공식화를 소개합니다. VLM은 단순히 2D 픽셀을 선택하고, 이는 저수준 SLAM 컨트롤러를 위한 3D 좌표로 투영됩니다. 이 설계는 VLM의 본래 2D 시각 능력과 자연스럽게 정렬됩니다. 둘째, 선택적 추론 및 앵커-경로 메모리 메커니즘을 제안합니다. 이는 중요한 노드에서만 고품질 메모리를 유지하고, 중복 경로를 경량화된 시공간 지표로 압축하여 중요한 역사적 정보를 보존하고 시공간 인식을 향상시킵니다. 마지막으로, 그룹 상대 정책 최적화를 통한 효율적인 이중 정렬 패러다임을 설계합니다. 전반적 결과 보상과 세밀한 프로세스 보상을 중첩함으로써, 촘촘한 감독이 에이전트의 인지 계획과 물리적 환경 피드백을 긴밀히 정렬하여 모델에 적응적 추론 능력을 부여합니다. 실험 결과, TAMP-Nav는 높은 실행 및 샘플 효율성으로 최첨단 성능을 달성했습니다 (예: R2R-CE에서 66.2% SR, 90k 훈련 경로만 필요).

### - 자동 부호화 변분 베이즈

**핵심 기여**:
- 표준 확률적 경사 하강법으로 최적화할 수 있는 변분 하한의 재매개변수를 도입합니다.
- 제안된 하한 추정기를 사용하여 비가산 사후 확률에 대한 근사 추론 모델을 적합하는 방법을 제안합니다.
- 제안된 접근법의 이론적 및 실험적 이점을 입증합니다.

**초록**:

연속적인 잠재 변수가 있는 방향성 확률 모델에서, 비가산 사후 확률 분포와 대규모 데이터셋이 있는 경우 효율적인 추론과 학습을 어떻게 수행할 수 있을까요? 우리는 대규모 데이터셋에도 확장 가능한 확률적 변분 추론 및 학습 알고리즘을 소개하며, 일부 미분 가능성 조건 하에서는 비가산 경우에서도 작동합니다. 우리의 기여는 두 가지입니다. 첫째, 변분 하한의 재매개변수가 표준 확률적 경사 하강법을 사용하여 쉽게 최적화할 수 있는 하한 추정기를 제공합니다. 둘째, 연속적인 잠재 변수가 있는 독립 동일 분포 데이터셋에 대해, 제안된 하한 추정기를 사용하여 비가산 사후 확률에 대한 근사 추론 모델(인식 모델이라고도 함)을 적합함으로써 사후 추론을 특히 효율적으로 만들 수 있음을 보여줍니다. 이론적 이점은 실험 결과에 반영됩니다.

### - DINOv2: 비지도 학습을 통한 강력한 시각적 특징 학습

**초록**:

대량의 데이터로 모델을 사전 학습하는 자연어 처리의 최근 발전은 컴퓨터 비전에서도 유사한 기반 모델의 가능성을 열었습니다. 이러한 모델은 이미지 분포와 작업에 관계없이 미세 조정 없이 작동하는 범용 시각적 특징을 생성하여 시스템에서 이미지 사용을 크게 단순화할 수 있습니다. 이 연구는 기존의 사전 학습 방법, 특히 자기 지도 방법이 다양한 출처의 충분한 큐레이션된 데이터로 학습될 때 이러한 특징을 생성할 수 있음을 보여줍니다. 우리는 기존 접근 방식을 재검토하고 데이터와 모델 크기 측면에서 사전 학습을 확장하기 위해 다양한 기술을 결합합니다. 기술적 기여의 대부분은 대규모로 학습을 가속화하고 안정화하는 데 중점을 둡니다. 데이터 측면에서, 우리는 일반적으로 자기 지도 문헌에서 사용하는 비큐레이션 데이터 대신 전용, 다양한, 큐레이션된 이미지 데이터셋을 구축하기 위한 자동 파이프라인을 제안합니다. 모델 측면에서, 우리는 1B 파라미터를 가진 ViT 모델을 학습하고 이를 이미지 및 픽셀 수준의 대부분의 벤치마크에서 최고의 범용 특징인 OpenCLIP을 능가하는 일련의 작은 모델로 증류합니다.

**핵심 기여**:
- 7B, 40B, 180B 파라미터의 파르콘 시리즈 오픈 언어 모델을 소개합니다.
